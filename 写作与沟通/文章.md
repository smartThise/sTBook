# 幻想世界中的暴力

《哈利·波特》作为一本主要面向青少年的魔幻题材小说，在前四部曲中，主人公们依靠自己的聪明才智与黑魔法势力斗智斗勇，虽然多有艰险，但还是能基本依仗着少年们无知无畏的个人英雄主义和邓布利多等人的背后支持解决问题。然而即使在魔法世界，这样的和谐也并非亘古不变。从第三部阿兹卡班与摄魂怪正式登场，到第四部魔法部官员们的百态显现，其实早已预兆了小说正在走向充满矛盾、冲突、暴力的成人世界。从第五部开始，暴力、反抗便成为了小说的重要组成部分，这其中无疑融入了作者对现实世界暴力事件、暴力组织的深刻反思，也值得我们深入探究。

通过对小说及其衍生作品的通读，我们大致可以将小说中的暴力组织分为两类：官方暴力机关和地下暴力组织。官方暴力机关主要包括魔法部魔法法律执行司、威森加摩、阿兹卡班监狱等，而地下暴力组织则包括邓布利多领导的凤凰社等多个地下抵抗组织、哈利·波特及其朋友领导的邓布利多军等，以及如食死徒等黑魔法暴力组织。不难发现，作者在创作此类内容时，往往将现实世界中的暴力组织作为原型，使得魔法世界中暴力组织的对抗故事在读者看来分外眼熟。

虽然在类型上与现实世界有相似之处，但作为一部魔幻题材小说，《哈利·波特》中的暴力组织在目的、组织架构、行为准则、彼此关系上又颇具特色，不能单纯以现实世界中的暴力组织来概括，应当视作作者结合了现代社会暴力组织和古代祭祀仪式、盟誓契约的传统关系的二次创作。如邓布利多军的告密者惩罚和凤凰社中赤胆忠心咒的特殊机制，都需要结合小说背景和魔法世界中的魔法知识来理解。

无论作者对书中的暴力组织进行了怎样的刻画，其目的无疑都是为了推动故事情节发展并表达作者自己的观点。为此，我们便需要考虑作者本人的早年复杂的生活经验等背景内容，方能对书中的暴力组织行为有更深刻的批判性理解。那么，我们应该怎样理解魔法世界中暴力组织的诞生与演变？他们与现实世界暴力组织之间会产生怎样的投射？我们从中又能获取哪些启发？

# 公共权力的诞生：魔法世界的暴力机关

我们在小说中首先认识到的无疑是以魔法部魔法法律执行司为代表的官方暴力机关，其来源便是魔法社会的公共权力的创立。根据恩格斯的《家庭、私有制和国家的起源》^[恩格斯：《家庭、私有制和国家的起源》，中共中央马克思恩格斯列宁斯大林著作编译局编译，北京：人民出版社，2018年，第189页]对公共权力的定义，公共权力即特权阶级所有的武装集团及其物质附属物，如监狱、其他强制场所，这在后来演变为了我们熟知的国家暴力机关的定义：军队、
警察、监狱（惩戒机构）、法院（司法系统）。

类比到魔法社会，魔法法律执行司旗下的傲罗办公室便是一个符合该定义的机构：他们由经历魔法社会层层筛选出的精英统治阶级组成，对魔法社会的稳定进行维护，必要时动用暴力手段维护治安，和学理意义上的警察概念相符。除此之外，威森加摩可与法院相对应，阿兹卡班与监狱对应。由此可见，在表面意义上，魔法世界拥有一套较为完善、与现实世界相契合的官方暴力机关。

然而熟读小说的读者都知道上面的描述并不准确——实际上，魔法世界的暴力机关的混乱程度令人无比抓狂。魔法部同时拥有最高的立法权、执法权，以及接近无限的法律解释权，并且在威森加摩中占有重要席位，可以说一部揽三权，实际上造成了魔法部拥有着堪称独裁机构般的无限制权力，其手中的暴力在名义上毫无限制，是一种接近初级国家阶段的无监督暴力^[恩格斯：《家庭、私有制和国家的起源》，中共中央马克思恩格斯列宁斯大林著作编译局编译，北京：人民出版社，2018年，第190页]。如在小说第四部中所说，当面对黑魔法势力的威胁时，巴蒂·克劳奇为代表的魔法部强硬派没有经过任何限制、选举和讨论便可以直接采用最极端的刑讯逼供手段进行无差别的严厉打击，实际上和黑魔法势力其残酷程度不相上下^[J. K. 罗琳：《哈利·波特与火焰杯》，马爱新译，北京：人民文学出版社，2014年，第381页]。当现代社会的公共权力回归到法制残缺时期的酷刑政治，将惩罚对象回归到肉体而非灵魂的改造时^[米歇尔·福柯：《规训与惩罚》，刘北成等译，北京：生活·读书·新知·三联书店，2012年，第17页]，我们很难认为魔法部及其附属机构这一套极端脆弱的暴力机关能有怎样的正常而符合社会要求的约束力。然而，从某种意义上来说，这其实是作者刻意进行的夸张刻画，目的便是为后续魔法部权力的膨胀、其对手中暴力的无限制滥用和被黑魔法势力入侵后的严重后果埋下伏笔。

从名义上来说，上述机关存在的目的即是为了维护魔法法律的执行，从而维护魔法社会正常运转。从表面上看，他们完成的并不那么尽如人意。不同于达米安·布利多诺对于《哈利·波特》中学院、议会制度及平等关系的论述^[达米安·布利多诺：《哈利·波特与历史》，赵飒译，中译出版社，2022年，第54页]，我更倾向于同意《哈利·波特中的政治学》一书中对这些暴力机关人员的相关论述：“百分之百的官僚机构。那里根本看不出有什么行政或立法部门，也没有选举。虽然有某种司法功能……根本无法对政府行为作出独立制约”^[贝瑟尼·巴拉特：《哈利·波特中的政治学》，朱晔，姜睿译，北京：中国财政经济出版社，2015年，第20页]。

投射到现实社会中，我们可以认为这些暴力机关是作者借魔法世界的壳创作的《是，大臣》类的讽刺产物。通过刻画这样一个极度夸张的、结构混乱的、丑态百出的暴力机关混合物，来影射现实政治中实际存在的丑态、敲响警钟。同时，她通过如金斯莱、唐克斯等人物的刻画，表明在这样混乱的暴力机关中也有人坚守正义底线与初心，也体现出她并未失去对现有体制的信心，并对现有机制的改革充满希望。

# 地下暴力组织的涌动：并不稳定的魔法社会

相比于冗杂的官方暴力机关，小说中更吸引读者的无疑还是众多的地下暴力组织。如果了解过《哈利·波特》的整体世界观，便一定会有一个深刻的印象：在这个魔法世界里，拥有暴力“武装”的地下结社、组织层出不穷，无论是出于爱好、黑魔法还是黑魔法防御的目的，此类组织都数不胜数，并且很多甚至抛头露面、在公开场合大肆活动，二这种现象在我们的“麻瓜”世界可以说是不敢想象的——至少在世界上大多数国家，没有几个是能容忍多如牛毛的暴力组织肆意妄为的。

魔法世界之所以能诞生这种独特的现象，究其本质还是魔法的特殊性质：作为一种正常世界规律无法解释的神秘现象，任何掌握魔法的巫师天生就具有强大的改造、控制与破坏能力，这种能力不像麻瓜们的枪支武器一样可以随意控制，加上官方暴力机关本来就效率低下、难以约束，致使只要巫师以“决斗”“防御术研究”等看似人畜无害的名义，结社便有了潜在的暴力组织特质。

一个有趣的例子便是：霍格沃茨学校本身算不算一个巨大的暴力组织？这个观点首先是由前魔法部部长康奈利·福吉先生提出的。在小说第五部中，哈利和朋友们秘密组建的黑魔法防御学习小组（本身也算小型地下暴力组织）被乌姆里奇发现之后，福吉看到“邓布利多军”的横幅之后，直接判定邓布利多正在将整个霍格沃茨变成一个巨大的、用于对抗魔法部的练兵场^[J. K. 罗琳：《哈利·波特与凤凰社》，马爱农，马爱新译，北京：人民文学出版社，2018年，第478页]；实际上，在第四部结尾也已经有福吉先生类似的表述出现。虽然福吉此时提出这个观点的目的是为了打倒邓布利多，但是从客观的角度讲，霍格沃茨确实一直“不是省油的灯”。霍格沃茨从始至终都对魔法部的相关法令表现出一定程度的抗拒——无论是在和平还是战争时期都是如此；他们确实在培养学生的决斗能力，在一段时期内（甚至可以考虑洛哈特时期）允许学生参与决斗；他们拥有堪称独立王国般的高度自治权，很多时候甚至可以称为邓布利多的“一言堂”，学生会、院长、校董会和魔法部、威森加摩甚至国际巫师联合会都在邓布利多的个人权威面前噤声，或者稍有反对终将被证明他们的错误。虽然这其中有大量作者的艺术加工，但是也使得霍格沃茨似乎超越了教书育人的学校的身份，成为了一个和魔法部分庭抗礼的独立准暴力组织。

在霍格沃茨之外，也不乏这样的魔法部很难管控的暴力组织，其中邓布利多又是其中多数组织的主要策划者。在第一次世界大战期间，为了对抗格林德沃，邓布利多便创立了凤凰社的雏形；在后来对抗伏地魔时，他又在不同国家创立大大小小多个抵抗组织。他的爱徒哈利显然也从中学到了组织和管理的重要经验，使得邓布利多军在后期成为了地位接近凤凰社的举足轻重的反抗组织。从这个角度看，地下暴力组织的蓬勃发展除去作者对邓布利多与哈利个人魅力的艺术性刻画，很大程度上其实也是官方暴力机关的不作为、乱作为引发的生态位空缺，使得必须有类似的地下组织填补相关领域治理的空白。如此，读者也能从中体会到一种混乱中重新建构的秩序感。在小说的结尾，罗琳让金斯莱成为魔法部部长，这也表明实际上她并不反对官方暴力机关，而是表达了她对官方暴力机关正规化、专业化的诉求，这也与二十世纪末二十一世纪初的普通民众诉求多相契合。

从古老的巫师议会到现代的逐渐改革的魔法部，从凤凰社到邓布利多军，魔法世界中官方暴力机关和地下暴力组织的螺旋式发展，同样折射出现实世界的制度的完善与进步，以及人们对稳定、和谐社会的朴素追求。期望麻瓜世界和魔法世界能够共同进步，最终走向人人高度自觉的先进社会，不辜负这番追求。
