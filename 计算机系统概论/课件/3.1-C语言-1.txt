变址模式


常见形式：D(Rb,Ri,S)      内存地址：Mem[Reg[Rb]+S*Reg[Ri]+D]

  D : 常量（地址偏移量）              Rb : 基址寄存器，16个通用寄存器之一

  D(Rb,Ri)    Mem[Reg[Rb]+Reg[Ri]+D]

X86-64下的简单寻址示例


 void swap(long *xp, long *yp)     swap:
 {                                  movq      (%rdi), %rax
   long t0 = *xp;                   movq      (%rsi), %rdx
   long t1 = *yp;                   movq      %rdx, (%rdi)
   *xp = t1;                        movq      %rax, (%rsi)
   *yp = t0;                        ret
 }

参数通过寄存器来传递                          注意
%rdi：第一个参数(xp) ；%rsi: 第二个        当参数少于7个时， 参数从左到右放入寄存器: rdi,
(yp)；参数类型为64位宽的指针                rsi, rdx, rcx, r8, r9。当参数为7个及以上时， 前6个
                                 传送方式不变， 但后面的依次从 "右向左" 放入栈中
