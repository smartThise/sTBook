## 一、填空题

### 第 1 题　三个"1"五个"0"的 8 位补码

8 位补码：符号位 1 → 负数，值 = −128 + 低 7 位无符号值；符号位 0 → 正数。三个 1 五个 0，符号位可 0 可 1，逐一构造：

- **最大的数**：取正数（符号位 0，不算 1），三个 1 全部放在剩余 7 位中尽可能高的位：
  `0111 0000` = **+112**
- **最小的数**：取负数（符号位 1）。负数越接近 −128 越小，即低 7 位应尽量小——两个 1 放最低两位：
  `1000 0011` = −128 + 3 = **−125**
  （对比：若把 1 放高位得 `1110 0000` = −32，明显大于 −125，不是最小）
- **绝对值最小的数**：正数候选中位串最小者：`0000 0111` = 7；负数候选中最接近 0 的是 `1110 0000` = −32。7 < 32，故取
  `0000 0111` = **7**

> 答案：最大 **01110000（+112）**；最小 **10000011（−125）**；绝对值最小 **00000111（+7）**

### 第 2 题　16 位补码加减（X = 0x2026，Y = 0xFACE）

**[X+Y]补**：直接相加，超出 16 位的进位丢弃（模 2¹⁶）：

```
  0x2026
+ 0xFACE
--------
 0x11AF4  → 丢弃第 17 位进位
```

**[X+Y]补 = 0x1AF4**

**[X−Y]补**：减法转加法，[−Y]补 = 对 [Y]补 按位取反加一：

```
~0xFACE = 0x0531，+1 → 0x0532
  0x2026
+ 0x0532
--------
  0x2558
```

**[X−Y]补 = 0x2558**

*十进制验算*：X = 8230，Y = 0xFACE − 0x10000 = −1330；X+Y = 6900 = 0x1AF4 ✓；X−Y = 9560 = 0x2558 ✓

### 第 3 题　FP8（E4M3 / E5M2）

参数：E4M3 → e=4, m=3, Bias = 2³−1 = 7；E5M2 → e=5, m=2, Bias = 2⁴−1 = 15。

#### (1)

**E4M3 最大非规格化数**：exp 全 0（非规格化），frac 取全 1（最大）：

- E = 1 − Bias = 1 − 7 = −6，M = 0.111₂ = 7/8
- 值 = 7/8 × 2⁻⁶ = 7 × 2⁻⁹
- 位串：`s=0, exp=0000, frac=111` → **`00000111`**

**E5M2 最大规格化数**：exp 全 1 保留给 inf/NaN，故 exp 最大为 `11110`：

- Exp = 30，E = 30 − 15 = 15，M = 1.11₂ = 7/4
- 值 = 7/4 × 2¹⁵ = 7 × 2¹³ = 57344
- 位串：`s=0, exp=11110, frac=11` → **`01111011`**

#### (2)

比较"最小正非规格化数"（exp 全 0，frac = 00…01）：

- E4M3：2⁻³ × 2⁻⁶ = 2⁻⁹
- E5M2：2⁻² × 2⁻¹⁴ = **2⁻¹⁶**（E = 1 − Bias = 1 − 15 = −14）

2⁻¹⁶ ≪ 2⁻⁹，**E5M2** 能表示更小的正数（指数位多 → 阶码下探更深）；其最小正非规格化数为 **2⁻¹⁶（= 1/65536）**。

*验证*：与课件 E4M3 表一致——E4M3 的 Bias=7，非规格化 E = 1−7 = −6，frac=001 时 1/8 × 1/64 = 1/512 = 2⁻⁹ ✓，说明公式确实是 E = 1 − Bias。

### 第 4 题　g = 2⁻¹³⁰ 的 BF16 / FP16 表示（就近舍入到偶数）

**BF16**（Bias = 127）：

- 规格化最小值 2⁻¹²⁶ > g → 走非规格化：值 = 0.frac₂ × 2⁻¹²⁶
- frac 需表示 g / 2⁻¹²⁶ = 2⁻¹³⁰⁺¹²⁶ = 2⁻⁴，即 frac = `0001000`（第 4 位为 1）——**精确表示，无需舍入**
- 位串：`0 00000000 0001000` → **0x0008**

**FP16**（Bias = 15）：

- 非规格化最小间隔 = 2⁻¹⁰ × 2⁻¹⁴ = 2⁻²⁴
- g / 2⁻²⁴ = 2⁻¹⁰⁶ ≪ 1/2：g 距离 0 不足"半个最小间隔"
- 就近舍入 → **舍入到 0**
- 位串：`0 00000 0000000000` → **0x0000**

> 答案：BF16 → **0x0008**；FP16 → **0x0000**
> 体会：BF16 指数位多，下溢边界约 2⁻¹³³；FP16 只能下探到约 2⁻²⁴，2⁻¹³⁰ 对它而言就是 0。

## 二、简答题

### 第 5 题　8 位定点 vs 浮点

**(1) 两者都有 2⁸ = 256 种位模式；若只统计不同的有限数值，定点数更多。**

- 定点（补码）：256 种位串与 256 个不同有限数值一一对应。
- 浮点：exp 全 1 的编码保留给 ±∞ 和 NaN（不是有限数值）；exp 全 0 且 frac 全 0 时 +0 与 −0 重复表示同一个 0。因此可表示的不同有限数值明显少于 256。

**(2) 三种场景选型：**

| 场景 | 选择 | 理由 |
|---|---|---|
| 梯度爆炸（趋向 ∞） | **FP8-E5M2** | 5 位指数 → 动态范围大（阶码约 −14 ~ +15），且 exp 全 1 有真正的 +∞ 表示，能容纳/标记爆炸的大梯度；E4M3 只有 4 位指数，范围窄 |
| 激活值稳定、要更多有效数字 | **FP8-E4M3** | 范围已稳定则不需要大指数域，把位宽让给尾数：E4M3 尾数 3 位（约 4 位有效数字），精度高于 E5M2 的 2 位 |
| 训练完成、对称量化部署（scale 已校准） | **INT8** | 量化后数值范围固定、间隔均匀，不再需要浮点指数的自动伸缩；对称量化即"乘 scale 后取整存为定点"，INT8 均匀网格精度最高、硬件最高效 |

一句话总结选型逻辑：**范围优先选 E5M2，精度优先选 E4M3，范围已知且均匀选 INT8。**

### 第 6 题　y = x × 25（≤4 次位运算/加减法）

把 25 拆成 2 的幂：25 = 32 − 8 + 1 = 2⁵ − 2³ + 1：

```c
y = (x << 5) - (x << 3) + x;   // 32x − 8x + x = 25x
```

运算次数：`x<<5`（1 次）+ `x<<3`（1 次）+ 减法（1 次）+ 加法（1 次）= **恰好 4 次** ✓

备选拆法（同样 4 次）：25 = 16 + 8 + 1，即 `(x<<4) + (x<<3) + x`。
对应汇编可用 `leaq` 一条完成部分工作：`leaq (%rax,%rax,8)` 可一步得到 9x，再 `salq` 与加法组合，同样不超过 4 次。
