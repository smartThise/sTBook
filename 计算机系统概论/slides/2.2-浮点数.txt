规格化浮点数 （ Normalized ）

 满足条件                 exp  000…0 且 exp  111…1

   真实的阶码值E（即指数）需要减去一个偏置量
   E = Exp – Bias
     Exp : 指数域所表示的无符号数值                             Bias的取值
     单精度数： 127 (Exp: 1…254, E: -126…127)          Bias = 2e-1 - 1, e表示exp域的位数
     双精度数： 1023 (Exp: 1…2046, E: -1022…1023)




   小数域的第一位隐含为1
   M = 1.xxx…x2
     因此，第一位的“1”可以省去
     当frac为000…0，值为最小，即M = 1.0
     当frac为111…1，值为最大，即M = 2.0 – ε             ε的值？

给定一个实数，如何给出其浮点数表示？

 基本流程
  首先计算出精确值
  然后将其转换为所需的精度
      • 可能会溢出（如果指数绝对值很大）
      • 可能需要完成舍入(rounding)操作


 各种舍入模式
                        $1.40   $1.60   $1.50   $2.50   –$1.50
  ◦ 向0舍入 （Zero）          $1     $1      $1      $2      –$1
  ◦ 向下舍入（Round down） $1         $1      $1      $2      –$2
  ◦ 向上舍入 (Round up)      $2     $2      $2      $3      –$1
  ◦ 向偶数舍入 (Nearest Even) $1     $2      $2      $2      –$2

向偶数舍入(Round-To-Even)

 计算机内默认舍入方式
   也称为“向最接近值的舍入”，其它方式会产生统计误差（statistically biased）


 确定两个可能结果的中间数值的舍入
   关键的设计决策是确定两个可能结果的中间数值的舍入

     • 确保舍入后的最低有效数字是偶数
     • 举例：保留百分位

      1.2349999   1.23   (不到一半)
      1.2350001   1.24   (大于一半)
      1.2350000   1.24   (恰好一半：为确保最低有效位为偶数，向上舍入)
      1.2450000   1.24   (恰好一半：为确保最低有效位为偶数，向下舍入)

      float 单精度浮点数                double 双精度浮点数

  型
  转      double 或 float 转换为 int
  换

            • 通常置为 Tmin or Tmax
         int转换为double
          ➢ 能够精确转换

         int转换为float
          ➢ 不会溢出，但是可能被舍入

Floating Point Puzzles


  以下判断是否成立，如不成立请给出反例

       int x = …;        • x ==      (int)(float) x
       float f = …;      • x ==      (int)(double) x
       double d = …;     • f == (float)(double) f
                         • d == (float) d
                         • f == -(-f);
       假设d 与 f 都不是 NaN   • 2/3 == 2/3.0
                         • d < 0.0       →   ((d*2) < 0.0)
                         • d>f           →   -f > -d
                         • d * d >= 0.0
                         • (d+f)-d == f
