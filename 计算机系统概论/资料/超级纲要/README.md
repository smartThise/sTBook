## 使用时的环境

主线采用教师课件的x86-64与AT&T语法，普通C例子说明LP64和C17假设；后续系统接口以POSIX/Linux语境解释。页表、缓存、分配器例题会在题面单独给出简化模型。若你的机器采用ARM64或Windows ABI，应先核对环境，再运行对应代码。

正文的编号Markdown与同名Typst共享内容。需要重建时，在仓库根目录运行`python3 工具脚本/教材/构建.py --course 计算机系统概论`；需要Pandoc、Typst和中文字体。原始课程文件仍在课程的slides、HW、公告、资料目录。
