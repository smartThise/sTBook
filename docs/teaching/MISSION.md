# 三门课教材的教学目标

读者会遇到陌生术语和符号，不应靠猜测填补教材的跳步。本轮先逐章修订数据结构，再以同一标准检查计算机系统概论和大学物理B(2)。

一段讲解应使读者能够从给定条件自己得到下一个状态：算法画出数据与控制状态，公式定义符号并解释变形理由，物理先画几何与方向，系统先标地址、寄存器和执行主体。复杂图使用完整原始课件页，或自行画出所需细节。原图旁解释如何读取，不能只贴图。

使用teach的资源核实与小步教学、wait-what的上下文与术语一致性、Humanizer的语言复审。将默认独立HTML课程形式适配为现有Markdown章节中的小节与可选演示；Markdown同时生成Typst。数据结构公开术语表在`数据结构/资料/超级纲要/96-符号与术语.md`，各例中仍局部定义变量，不能用术语表代替首次解释。

不记录未经读者验证的“掌握程度”。检查时用不同输入复演、数学推导和图形核对发现缺口；字数、页数、图数和测试数量均不能作为教学达标的替代。
