# 核实与学习材料

课程本地资料优先，逐门课的95章列出实际文件、原图页码、教材与PA/PS对应及覆盖边界。下列资料提供另一种教学组织，不能据此扩张考试范围，也不应照搬其与课程不同的符号或算法版本。

- Deng《数据结构》官方材料：<https://dsa.cs.tsinghua.edu.cn/~deng/ds/dsacpp/>。本地已取得2026教材及官方第三版教材与习题解析合体。
- Sedgewick、Wayne，《Algorithms》官方配套：<https://algs4.cs.princeton.edu/14analysis/>、<https://algs4.cs.princeton.edu/22mergesort/>、<https://algs4.cs.princeton.edu/33balanced/>、<https://algs4.cs.princeton.edu/44sp/>。分别用于具体操作计数、归并过程、搜索树结构和路径更新的对照。目录页有时403，须使用实际可读取的正文、官方实现或PDF，不把链接存在当作已读。
- Jeff Erickson，《Algorithms》及补充讲义：<https://jeffe.cs.illinois.edu/teaching/algorithms/>。动态规划重视先定义递归子问题、论证依赖，再安排计算顺序；补充讲义中摊还与离散概率用于核对成本模型与随机变量定义。该教材有先修要求，不能直接把原文浓缩后当零基础讲义。
- Bryant、O'Hallaron，《Computer Systems: A Programmer's Perspective》官方：<https://csapp.cs.cmu.edu/3e/home.html>。本地教师课件与此书选节对照；接口与语言规则另核实官方标准或平台手册。
- Arpaci-Dusseau，《Operating Systems: Three Easy Pieces》并发入门：<https://pages.cs.wisc.edu/~remzi/OSTEP/threads-intro.pdf>。参考其逐指令执行状态的组织；区分机器交错示意与C/C++数据竞争的未定义行为，不能给普通有竞态程序承诺唯一结果。
- OpenStax，《University Physics》第二、三卷：<https://openstax.org/details/books/university-physics-volume-2>、<https://openstax.org/details/books/university-physics-volume-3>。几何、策略、推导、单位与结果检查分步对照；公式需连同坐标和前提讲解，重新组织自编例子。
