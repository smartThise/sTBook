# 教材讲解与复读规范

读者是正在学习课程的大学生。正文用正常、连贯的段落，清楚交代对象、动作和理由。关键机制值得展开，已经说明的基础不必反复拆说。耐心体现在把困难讲清楚，不体现在夸奖、感叹、模拟聊天或给内容贴上“简单”的标签。

《啊哈C语言》《啊哈算法》的参考价值主要在讲解的推进：保留一个具体任务，让旧办法先完成它能完成的部分，再由真实困难引出新办法。课程的知识范围、符号、算法版本、代码接口和证明要求，以教师资料为准。参考书中的平台假设、旧接口、简化论断及局部错误不能随讲法一起移入正文。

## 从读者眼前能完成的事情往下写

一个知识点出现时，先交代正在处理什么、已有信息是什么、要得到什么。新名词应能指回具体对象。算法的输入、物理模型、机器状态与必要约定要在第一次使用前给出，避免让读者同时猜数据、规则和目标。

不要求每节都编一个故事或套同一组标题。已有清楚算例的地方，调整顺序并补缺失的因果关系即可。旧办法没有明显困难时，也不必故意制造错误。需要展示错误时，要手工走到实际坏掉的位置，并紧接着给出修正。

同一例子的数值、变量和图尽量贯穿完整过程。换输入应有目的，例如触发相等分支、空输入、无法到达的位置、负电荷或缓存未命中。连续几个互不相干的小算例，不能代替一个完整过程。

## 把改变状态的动作讲完整

数组赋值要说明读哪个旧值、写哪个位置、被覆盖的内容是否还需要；不能将复制画成数值自动消失的物理移动。指针赋值要说明改的是哪一节点的哪一字段，节点本身是否移动。递归要同时交代进入时的任务和返回后尚待完成的操作。

树旋转、分裂、合并和删除不能只画初态与终态。中间子树的归属、父链接、颜色、关键码及孩子指针都应能追踪。图论算法应把当前节点、待处理容器、已发现集合和正在修改的距离区分开。

访问标记保存什么事实，由任务决定。枚举当前路线的标记可能需要撤销；连通性搜索的发现标记通常永久保留；BFS应在入队时标记。不能只因都写了DFS，就给出同一套未经解释的模板。

物理计算先给几何位置、坐标、方向、单位和模型条件，再引入变量。离散求和过渡到积分时，要解释小段、面片或体元包含多少电荷，变量在哪个范围变化，方向分量怎样相加。不能用积分号替代这些工作。

## 由完整算例推广为规则和证明

代码前应已经有可以手工执行的规则；代码中的每个更新都应对应刚才发生的一步。完整可运行代码应有明确输入输出并实际验证。解释片段时，写清哪些状态已由调用者给定，不宣称片段可直接运行。

公式里的符号在首次使用时定义。每个非平凡等号或不等号要有理由：分类是否覆盖所有情况、是否重复计数、是否用了对称性、是否依赖正数或独立性。复杂度不能从“有两层循环”“交换得远”“大致减半”直接跳到结论。

证明应接住例子。先指出例子中哪条关系始终成立，再检查初始化、保持和退出；先列出实际各层工作，再写递推式及渐近界。一个算例成功不能证明所有输入成立，松上界不能直接改写为紧确界。

教师接口与便于讲解的接口不同时，应在读者需要转换处说明差异并给出对应过程。例如最大区间是否允许空区间、相等时短者与靠后者的优先级，查找返回任意命中还是边界，表达式乘方的结合性。这些差异必须能用于实际答题。

## 图应参与讲解，静态书也应能独立读懂

复杂图使用教师完整原页，或自绘完整步骤。正文要指出本步对应图中哪些对象、箭头和颜色。原页放在相关推导旁边，并注明具体来源与页码；不能用章末一张总图替代步骤。

网页演示与静态图使用相同状态。滑块、播放和拖动帮助观察，PDF仍须保留理解所需的关键帧、图例和解释。排版检查既看字是否超界，也看公式语义、图中文字、分页是否打断一个必须同时观察的状态。

原书电子文件、全文和插图只用于本地阅读，不纳入公开仓库。教材使用原创措辞与自绘算例；课程原图按既有资料范围引用。个人信息和被忽略的本地资料继续留在原位置。

## 独立复读

复读者先按初次学习者的顺序读，记录第一处不能判断下一步怎么做的地方，再换一个有辨别力的输入，仅凭正文重演。指出具体缺失的信息及其应出现的位置，不以字数、页数、图片数量或标题齐全判断完成。

写作者据此修正文，再核对教师原页、既有勘误、PA和PS接口。已有核准的正确结论不能为了顺口而删掉前提。术语表供回查，不能代替当前正在使用的概念解释。
