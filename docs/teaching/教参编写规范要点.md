# 教参编写规范要点（本笔记执行标准）

依据三类权威材料提炼，作为三科笔记的语言与编写准则。写作与审稿均按此执行。

## 一、国家标准与管理办法

1. **教育部《普通高等学校教材管理办法》（教材〔2019〕3号）第十三条**：教材编写应"结构严谨、逻辑性强、体系完备，能反映教学内容的内在联系、发展规律及学科专业特有的思维方式"；"全面准确阐述学科专业的基本理论、基础知识、基本方法和学术体系"；"编排科学合理，符合学术规范"；"富有启发性，有利于激发学习兴趣及创新潜能"。
2. **《标点符号用法》（GB/T 15834—2011）与《图书编校质量差错认定细则》**：分号只用于并列复句的第一层；顿号只用于并列词语；括号注释紧贴被注释成分；冒号一句内不重复；引文末标点按引文独立性安放；"两个句号/一逗到底"均为差错。
3. **《出版物上数字用法》（GB/T 15835—2011）**：物理量值与计数用阿拉伯数字（3人、50元、n=7）；定型词组中的数字用汉字（三等分、九九乘法表、七年之丧）；相邻数字概数不加顿号（"七八个"）；数值范围用浪纹号"～"或一字线；数字不与"万、亿"之外的汉字数词连用。
4. **《量和单位》（GB 3100～3102—1993）**：量符号用斜体（n、T、S、φ）；单位用规范符号（km/h、10⁹次每秒），不用"秒数、米数、摩尔数"一类自造名称。
5. **人教社课文加工原则（叶圣陶"文质兼美"；黄光硕"错了才改，可改可不改的不改"）**：语言"合乎现代汉语规范，用语、用字准确，条理清晰"；修改以最小改动为度；引用要有出处。

## 二、统编高中语文教材编者语言（单元导语、学习提示、单元学习任务、写作指导、活动提示）的写法特征

以必修上册八个单元的编者文字为范本：

1. **先断言，后依据**："写议论文，要有现实针对性。人们发表议论，往往是针对现实生活中的某个问题……" 观点句一律前置，理由随后，不倒装悬念。
2. **祈使句具体可执行**："阅读时注意领略……，品味……""要反复诵读，仔细揣摩"。每条指令都点名确切的动作与对象；禁止空泛的"想一想""体会一下"。
3. **列举用"或……或……"**："本单元作品，或报道……，或倡导……，或歌咏……" 并列内容一目了然。
4. **对仗短句只作开篇概括**："劳动改造世界，劳动创造文明。" 一处足矣，不成串。
5. **限定词准确且不堆叠**："大多""往往""一般""比较好的办法是""很有必要"——每处断言一个限定词。
6. **禁止性语句少而重**："切忌笼统、含糊不清"，出现在真正易错处。
7. **术语随文即释**："'志'是记述、记载的意思。如地方志，就是如实记载某一地方历史的书或文章。" 同位语解释，不甩名词。
8. **步骤化表述**：活动提示以"先……再……然后……最后"编号推进，每步含对象与动作。
9. **问题设计可作答**：思考题问"作品中哪些地方最让你感动？哪些是读过之后感受很深的？"——答案都能在文本中落实。
10. **教材自定的语言标准**："语言力求准确、平实、简明。"（必修上第四单元活动提示原文）

## 三、落实到本笔记的执行细则

1. 每章结构固定：引入（具体任务或问题）→ 概念定义 → 算法/公式及其推导 → 具体输入的完整执行 → 复杂度/结论 → 与前后章节的衔接 → 本章要点。
2. 每个论断必须紧跟依据：或给出推导，或指明"证明见某章"，或注明教师讲义/教材页码出处。不允许无根据断言。
3. 比喻限用有结构对应关系者（气泡上浮之于冒泡排序、绳线之于递归深度），一章至多一两处，且须服务于理解；网络流行语、无出处的掉书袋典故一律不用。
4. 表格与图的每一列（每一元素）都在正文中交代读法；执行表格逐行与代码对应。
5. 术语全书一致，首次出现给定义并括注英文；以96章符号表为准。
6. 疑难处以教师课件为准；课件笔误照实勘误并注明位置。
7. 修订原则从黄光硕："错了才改，可改可不改的不改"；引用原书、课件处标注来源。
