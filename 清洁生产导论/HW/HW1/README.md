## 作业要求

作业内容:

请同学们仔细体会清洁生产13322密码的启示，结合自己的专业、感兴趣的产品或事物等，用形象化的方式，用一张图体现清洁生产思想。自己专业、感兴趣的产品或事物:以机械专业为例，可以选汽车零部件;对能源主题相关的同学，可以选风机叶片;日常事物可以选手机、一次性产品等，充分发挥想象力和主观能动性。形象化的方式：可以是PPT绘图，可以是手绘图，也可以是AI创作的图。

使用AI的作业应注明来源并附带文字说明。
 提交方式:

一张A4大小的图，横向纵向排版均可，PDF格式提交网络学堂。

提交时间:

2026年9月29日23:59前，10月14日邀请2-3位同学进行课堂分享

注：第一次作业为单人作业，需要每个人提交自己的作品。

附件提供了往年优秀作业案例，供大家参考。
