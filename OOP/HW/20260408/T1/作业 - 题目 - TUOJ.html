选择题（2026第二次作业）

若对编译命令无特殊说明，所有题在编译时默认添加选项 --std=c++11

1. 【多选题】关于构造函数的执行，阅读以下代码并选出正确的说法：

#include <iostream>
using namespace std;

class Member {
public:
    Member() { cout << "M"; }
    ~Member() { cout << "~M"; }
};

class Base {
    Member m;
public:
    Base() { cout << "B"; }
    ~Base() { cout << "~B"; }
};

int main() {
    Base* b = new Base();
    delete b;
    return 0;
}

A. 程序运行的输出结果是 MB~B~M。

B. 构造函数的执行顺序是：先执行成员对象的构造函数，再执行类自身的构造函数体。

C. 析构函数的执行顺序是：先执行类自身的析构函数体，再执行成员对象的析构函数。

D. 如果将 main 函数中的 delete b; 删除，程序依然会输出 ~B~M，因为对象超出了作用域。

2. 【单选题】关于“引用”与代码安全性，下列说法错误的是：

A. 引用在定义时必须初始化，且一旦绑定到一个对象，就不能再改为引用其他对象。

B. 返回局部变量的引用是危险的，因为局部变量在函数结束时会被销毁，导致引用指向无效内存。

C. 常引用（const T&）既可以绑定到左值，也可以绑定到右值。

D. 所有的运算符重载函数都必须返回引用，以保证链式调用（如 a + b + c）的效率。

3. 【多选题】在C++中使用 new 和 delete 时，下列哪些描述符合课程讲义规范？

A. new 运算分为两步：首先分配足够的原始内存，然后调用相应的构造函数初始化对象。

B. 对于 int* p = new int[10];，使用 delete p; 是完全安全的，编译器会自动识别它是数组。

C. 执行 delete 之后，指针变量本身的值（内存地址）不会自动变为 nullptr，该指针会变成“悬空指针”。

D. 静态成员变量（static data member）不能在构造函数中使用 new 进行初始化，因为它们属于类而不属于对象。

4. 【单选题】关于静态成员（Static Members），下列说法正确的是：

A. 静态成员函数可以访问类中的任何成员，包括非静态数据成员和 this 指针。

B. 静态数据成员必须在类外进行定义和初始化（除少数特定情况如 static const int 外），否则链接时会报错。

C. 每一个对象都拥有一份静态数据成员的独立拷贝。

D. 静态成员函数只能通过类名调用（如 Test::func()），不能通过对象名调用。

5. 【多选题】阅读以下关于运算符重载的代码，选出正确的选项：

class Complex {
    double real, imag;
public:
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}
    // (A) 成员函数重载
    Complex operator+(const Complex& other) {
        return Complex(real + other.real, imag + other.imag);
    }
    // (B) 友元函数重载
    friend Complex operator-(const Complex& c1, const Complex& c2);
};

A. 运算符重载不能改变运算符的优先级、结合性以及操作数的个数。

B. 对于 + 运算符，若采用成员函数重载（如A处），则第一个操作数必须是该类的对象。

C. 赋值运算符 =、下标运算符 []、函数调用运算符 () 必须重载为成员函数。

D. 所有的 C++ 运算符都可以被重载，包括 . (成员访问) 和 :: (作用域解析)。

6. 【单选题】关于析构函数的触发时机，下列说法错误的是：

A. 局部非静态对象在程序离开其所在的作用域（如函数结束或花括号结束）时自动析构。

B. 全局对象在 main 函数执行结束返回后被析构。

C. 使用 new 创建的对象，其析构函数在程序结束时由操作系统强制自动调用，程序员无需关心。

D. 静态局部对象（static 修饰的局部变量）在 main 函数结束时析构。

7. 【单选题】关于友元（Friend），下列描述正确的是：

A. 友元关系是可以传递的，即“朋友的朋友也是朋友”。

B. 友元关系是双向的，若类 A 是类 B 的友元，则类 B 也是类 A 的友元。

C. 友元声明必须放在类的 public 区域才能生效。

D. 友元函数虽然在类内声明，但它不是该类的成员函数，调用时不依赖于对象。

8. 【多选题】针对 C++11 特性与类成员初始化，下列说法错误的是：

A. 在 C++11 中，可以在类定义内为非静态成员变量直接给定初始值（如 int a = 10;）。

B. 构造函数的初始化列表（Initialization List）的执行顺序是按照它们在初始化列表中出现的顺序决定的。

C. Test() = default; 显式要求编译器生成默认构造函数。

D. 常量数据成员（const data member）可以在构造函数体内部通过赋值语句进行初始化。
