# sTBook

我的课程笔记库，同时作为 [个人网站](https://guojl06.github.io) 笔记/知识库模块的数据源（wiki 风格，可在线浏览 md / typst / pdf / 图片 / 数据文件）。

## 结构

- [课程资料索引](课程索引.md)：各课程直接按 `slides/`、`HW/`、`公告/`、`资料/` 分类，已有作业与新资料放在一起。
- 课程文件夹：直接使用中文课程名，如 `数据结构/`、`面向对象程序设计基础/`、`离散数学(2)/`、`大学物理(1)(英)/`、`AI4S 交叉实践课程/`。
- [`wiki.yml`](wiki.yml) 记录目录、分组与简介；目录名、网站路径和展示名一致，无需英文名称映射。
- `Assets/`、`module/`：共享图片与 Typst 工具模块，笔记内以相对路径引用，**勿改名**
- `模板/`：简历等模板；`工具脚本/`：OJ→Markdown 等脚本；`杂项/`：个人杂项

课程目录改名时，同时更新 `wiki.yml` 和 `.gitignore` 中的对应路径。

## 网站同步

把笔记 push 到 GitHub 本仓库的 `main` 分支后，
[guojl06.github.io/notes](https://guojl06.github.io/notes/) 会直接读取最新目录和资源。
刷新网页即可读取最新提交；已打开的页面每 15 秒检查更新，切回页面时也会检查，无需等待 Actions 构建。

后台 GitHub Action 继续生成静态快照和 Typst PDF 预览。Typst 源文即时可读；PDF 需等后台编译完成，且版本与当前提交一致时才作为默认预览。

隐私文件保留在本地原位置，通过 `.gitignore` 排除；转系面试、个人照片、群聊二维码、访问凭据和个人批改记录不参与公开发布。

数据结构课程的 HW、PA、Lab（含代码、题目、报告、测试数据与附件）仅保留在本地，不参与 Git 提交、GitHub Release 或网站发布。已经跟踪的文件须先用 `git rm --cached` 取消跟踪；不要用 `git add -f` 绕过规则。
