# 数据结构答疑辅导安排 & 学习资源介绍

[返回公告目录](README.md)

发布：2026-09-13 18:00　张朋乐

为了帮助同学们更好地理解数据结构与算法背后的原理，课程组准备了以下答疑渠道和学习资源。 

   **课程答疑**

本学期提供以下两种答疑渠道： 

1. 课后线下答疑 

每个教学班每周安排一次由助教负责的课后线下答疑：邓俊辉老师班为周一，尹霞老师班和陈键飞老师班为周五。线下答疑主要适合**代码调试**等较为复杂、需要即时交流的问题。 

为了让尽可能多的同学得到帮助，助教通常会优先指出下一步可以尝试的调试方向，而不是直接解决全部问题。建议大家**尽早开始完成作业**并及时提问，避免在截止日期前积累大量尚未解决的问题。 

2. 网络学堂线上答疑 

线上答疑在网络学堂的“课程答疑”模块进行。同学可以在此发帖提问，所发内容仅本人和课程教师、助教可见。助教一般会在 24 小时内响应。 

为提高答疑效率，请清晰、完整地描述问题以及已经尝试过的解决方法。代码调试类问题通常较为复杂，建议优先利用课后线下答疑。如果长时间未收到响应，请检查“开放答疑”开关是否处于“开放”状态。 

与课程相关的通知，包括**成绩公布及复议、答疑安排调整等，都会通过网络学堂公告**发布。请及时关注网络学堂，以免错过重要通知。大家可以在微信中订阅“清华大学信息服务”以接收网络学堂通知；网络学堂默认也会向清华邮箱发送课程公告邮件，可按需配置邮件提醒。 

    

   **线上学习资源**

以下资源均可在网络学堂“课程文件”中下载。 

1. 示例代码包 

课程中讲授的数据结构基本都包含在示例代码包中。代码包按 Visual Studio 2022 的项目格式，将 60 多个项目组织为一个解决方案，可以直接编译、运行。这些代码既能演示数据结构与算法的原理和机制，也能直观展示其运行与演化过程。 

在编程作业中可以使用示例代码，但**必须在 Honor Code 中声明，并对其中可能存在的问题自行承担责任**。 

2. 演示程序 

演示程序按运行平台分为 Excel 和 Java Applet 两类。 

- Excel 演示程序：打开文件后可查看使用说明。通常不断按下 F9 键即可观察对应算法的执行过程；部分复杂算法可能需要先解锁相应开关。如果电脑默认将 F1 至 F12 用作多媒体快捷键，可以使用 Fn 或 Fn Lock 切换，也可以在 BIOS 中将这些按键设置为 Legacy 模式。此类程序在手机上可能无法正常运行，建议使用电脑打开。 

- Java Applet 演示程序：运行前请确认已经安装 Java AppletViewer。资源压缩包中提供了安装程序和简要说明。可以使用 AppletViewer 打开各演示对应的 index.applet 文件，也可以将 .applet 文件统一关联到 AppletViewer。具体使用方法可查看[邓老师的讲解视频](https://cloud.tsinghua.edu.cn/f/a1b04e0929204500abb9/)。如果在 Windows 10 或 Windows 11 中遇到闪退，请检查 Java 环境变量是否配置正确，可参考 [Windows Java 环境配置教程](https://www.runoob.com/w3cnote/windows10-java-setup.html)。 

如果使用演示程序时仍有无法解决的问题，欢迎在网络学堂“课程答疑”模块提问。 

3. 编程作业思路讲解 

针对编程作业中可能遇到的难点，课程组准备了解题思路的提示与讲解，并会在作业发布一段时间后上传至网络学堂。 

建议大家先根据题目中的简要提示独立思考。遇到困难时，可以阅读思路讲解，其中包含更细致的解题提示以及对往届常见错误的说明。如果这些材料仍不能解决问题，欢迎通过网络学堂线上答疑或课后线下答疑继续咨询。 

Syllabus 中还列出了问题集、慕课等其他学习资源。期待大家在数据结构课程中学有所获！
