# 题目没有告诉你用什么结构时，先算一个小输入

下面八题都先确定操作和答案，再选择要维护的状态。读到一个步骤时，可以盖住下一行，自己画一次数组、树或队列；旁边的状态不是装饰，它应当能用来查出自己的第一处错误。

## 订单按到达顺序处理，还要随时知道最大金额

输入操作为：入A金额5、入B金额2、查最大、出单、入C金额7、查最大、出单、查最大、出单。出单必须先进先出。若只用普通队列，每次查最大要扫当前所有订单，重复查询可能二次。

用两个栈组成队列，每个栈格保存`(订单,金额,从栈底到此格的最大金额)`。这样一只栈的最大就是顶格附带的摘要，弹出后新栈顶自动给出剩余部分的最大，无需重扫。

in接收新单，out负责出单，只有out为空时才倒栈。每个格以下简写为`订单:金额/本格最大`，均从底到顶书写：

| 操作 | in | out | 返回 |
|---|---|---|---|
| 入A5 | `[A:5/5]` | `[]` | — |
| 入B2 | `[A:5/5,B:2/5]` | `[]` | — |
| 查最大 | 同上 | 空 | 5 |
| 出单 | `[]` | 倒完为`[B:2/2,A:5/5]`，再弹A，剩`[B:2/2]` | A |
| 入C7 | `[C:7/7]` | `[B:2/2]` | — |
| 查最大 | 同上 | 同上 | max(7,2)=7 |
| 出单 | `[C:7/7]` | `[]` | B |
| 查最大 | `[C:7/7]` | `[]` | 7 |
| 出单 | `[]` | C倒入后再弹，清空 | C |

为什么in里新来的C不会越过旧B？out非空时始终先用out，不因为新单到来而重倒。倒栈又把in的后进先出反转一次，使最早入in的单处于out顶。两只栈各自的最大取max，恰好覆盖当前队列全部元素；空栈的摘要用“无值”表示，别用0，否则全负金额模型会误报0。

每项至多进in、离in、进out、离out各一次，所以m次操作总$O(m)$，查询最大最坏$O(1)$，空间与当前订单数同阶。某一次出单倒很多项仍可能线性，这个方案给摊还保证；要求每次都严格常数延迟的系统，需要另外的逐步迁移方案。

## 成绩序列：两个2能不能都选，先看等号

记录按到达顺序为`[3,1,2,2,4]`，允许跳过，禁止重排。找最长不下降子序列时，1、2、2、4合法，长度4；找严格上升时不能连两个2，答案长度3。

先写慢DP。设$f_i$表示必须以第i项结束的最佳长度，初值1；每个前驱j需满足j<i且$a_j\le a_i$。把所有合法前驱的$f_j+1$取最大：

| i / 值 | 合法前驱 | 当前$f_i$ | 一条达到它的链 |
|---|---|---:|---|
| 0 / 3 | 无 | 1 | 3 |
| 1 / 1 | 无 | 1 | 1 |
| 2 / 2 | 下标1的1 | 2 | 1,2 |
| 3 / 2 | 下标1的1、下标2的2 | 3 | 1,2,2 |
| 4 / 4 | 前面全部 | 4 | 1,2,2,4 |

每项扫前面全部，时间$O(n^2)$。若把≤改<，下标3不能接2，得到$f=[1,1,2,2,3]$，精确体现题意差别。

加速时，`tails[l-1]`只保存“已经见过的、长度为l的不降子序列中，最小的末尾值”。长度相同，末尾越小，未来可接的新值至少不会更少。新值x应接在所有末尾≤x的长度后面，因此找第一个**严格大于x**的位置，使用upper_bound：

```text
读3：tails=[]，位置0，追加       -> [3]
读1：首个>1是下标0，替换       -> [1]
读2：没有>2，位置1，追加       -> [1,2]
再读2：没有>2，位置2，追加     -> [1,2,2]
读4：没有>4，位置3，追加       -> [1,2,2,4]
```

位置p是零起下标，代表新项可以成为长度p+1的末尾。为什么？p前面的末尾都≤x，所以长度p的代表链可以接上x；p=0时，x自己就形成长度1。另一方面，旧tails[p]若存在就严格大于x，说明任何长度p+1的旧链末尾都大于x，不能接x。因此新项不能一下产生长度p+2或更长的链。这个上、下两面一起证明了新长度恰为p+1。

更新时，长度p+1原来的最小末尾若存在，就用更小的x替换；若不存在，就新增长度。其他长度不变。这既保留了每个长度的可行链，也保留了“同长度末尾最小”的含义。tails仍然非降，可以继续二分。每项O(log n)，总O(n log n)。

### 恢复的是一条链，不能直接打印tails

读`[2,3,1]`后tails为`[1,3]`，但1出现晚于3，它们不是原输入中的子序列。tails的每一格各自代表一种长度，格与格可能来自不同链。

要恢复一条答案，同时存`end[p]`：长度p+1的代表链末项在原数组中的下标；`parent[i]`：以第i项结尾的这条链，上一项的原下标。新项落p时，先读取更新前的end[p−1]作为前驱，再把end[p]改成i。−1表示没有前驱。

|i / x|二分位置p|先保存parent[i]|更新后的tails|更新后的end|
|---|---:|---:|---|---|
|0 / 3|0|−1|[3]|[0]|
|1 / 1|0|−1|[1]|[1]|
|2 / 2|1|1|[1,2]|[1,2]|
|3 / 2|2|2|[1,2,2]|[1,2,3]|
|4 / 4|3|3|[1,2,2,4]|[1,2,3,4]|

最后从end[3]=4开始沿parent回退：原下标4→3→2→1→−1，对应数值4→2→2→1；反转后得到[1,2,2,4]。以后某个end格被替换，不会改写已经保存的parent链接，因为parent记的是原数组下标，不是会变化的tails位置。

```python
from bisect import bisect_right

def longest_nondecreasing(a):
    tails, end = [], []
    parent = [-1] * len(a)
    for i, x in enumerate(a):
        p = bisect_right(tails, x)  # 第一个严格大于x
        if p > 0:
            parent[i] = end[p - 1]  # 先保存旧代表
        if p == len(tails):
            tails.append(x)
            end.append(i)
        else:
            tails[p] = x
            end[p] = i
    indices = []
    i = end[-1] if end else -1
    while i != -1:
        indices.append(i)
        i = parent[i]
    indices.reverse()
    return indices  # 用[a[i] for i in indices]取得数值
```

前驱下标严格小于当前下标，链不会成环，恢复次数不超过n。空输入返回空下标列表。严格上升版把bisect_right改为bisect_left，即找第一个≥x的位置；这样等值项只替换旧代表，不增长长度。

## 道路网络：哪个路口一删，连通块就增多

无向简单图边为1—2、2—3、3—1、3—4、4—5。前面是一个三角形，后面接一条链：

```text
  1 ----- 2
   \     /
     3 ----- 4 ----- 5
```

慢办法逐个删除顶点后重跑连通性。一次DFS可同时找割点与桥：`dfn[v]`记首次发现次序；`low[v]`记v子树沿树边向下、最多再用一条回祖先边，能到达的最小发现号。只看“有没有回边”不够，还要知道能绕到父亲之上哪一层。

固定邻居访问顺序，使DFS树走1→2→3→4→5：

| 事件 | dfn/low发生的变化 |
|---|---|
| 发现1、2、3 | 各自dfn为1、2、3，low先等于自己dfn |
| 3看到已访问祖先1 | `low[3]=min(3,dfn[1])=1` |
| 发现4、5 | dfn为4、5，low初值4、5 |
| 5返回4 | 没有回边，low5=5；5>dfn4=4，所以4—5是桥；5≥4，所以非根4是割点 |
| 4返回3 | low4=4；4>dfn3=3，所以3—4是桥；4≥3，所以3是割点；low3仍min(1,4)=1 |
| 3返回2 | low3=1<dfn2=2，子树可绕过2到1，2不是割点；low2改1 |
| 2返回1 | 根1只有一个DFS树孩子2，所以不是割点 |

根虽然与2、3都相邻，但3在2的递归过程中已经被发现，不能把两条邻边当两个DFS树孩子。最终割点3、4，桥3—4、4—5。割点条件用≥，桥用>：若孩子能回到父亲本身，边不一定是桥，但删掉父亲仍可能断开子树。

每条无向边扫描常数次，时间$O(V+E)$。若有平行边，要按边ID识别“刚才来的父边”，否则把另一条回父边一并跳过会误报桥。这个简单例子的证明不能靠省掉多重边约定来冒充一般实现。

## 反复插入、删除以后，仍要能查第k小

依次插8、3、10、1、6，重复值暂不允许，查询第3小；再删3，再查第3小。只用普通散列表找不到全局秩；可以用平衡BST，并给每个节点额外保存子树节点数size。

插入后的合法AVL形状可以是：

```text
        8(size=5)
       /         \
  3(size=3)     10(size=1)
   /     \
 1(1)    6(1)
```

查询节点v时，左子树大小记L。按中序，左边恰占前L名，v自己是L+1名；目标k≤L就去左边，k=L+1返回v，否则去右边，并把k减去L+1。

| 当前节点 | 左大小L | 当前k | 决定 |
|---:|---:|---:|---|
| 8 | 3 | 3 | 3≤3，去左 |
| 3 | 1 | 3 | 越过左边1项和根，k改1，去右 |
| 6 | 0 | 1 | 1=L+1，返回6 |

删3时用其后继6替换并删除原6节点，左子树变根6、左孩子1。原根8的左大小从3变2，所以第二次查询k=3，直接在8返回。全序也确实由`1,3,6,8,10`变为`1,6,8,10`。

维护式是`size(v)=1+size(left)+size(right)`，空子树size=0。每次修改或旋转都要更新；旋转先更新变低的节点，再更新新根，否则新根会读到旧摘要。高度没变时可以停止高度传播，size却可能继续变，不能一起停止。平衡树高度$O(\log n)$，所以四种接口均可对数；k必须在1到当前size之间，空树没有第1小。

## 矩形内的点：计数摘要与输出全部是两种任务

点为(1,1)、(2,4)、(3,2)、(4,5)、(5,3)，查询闭矩形$[2,5]\times[2,5]$。逐点答案是后4个点，计数4。

设kd树根点为(3,2)，左子树保存前两点，包围盒$[1,2]\times[1,4]$；右子树保存后两点，包围盒$[4,5]\times[3,5]$。每个节点保存size和包围盒：

| 要检查的对象 | 与查询的关系 | 计数操作 |
|---|---|---|
| 根点(3,2) | 在闭矩形内，包括边界 | +1 |
| 左子树包围盒 | 部分相交 | 继续分开检查 |
| 左点(1,1) | 外部 | +0 |
| 左点(2,4) | 边界上 | +1 |
| 右子树包围盒 | 整个包含 | 直接加size=2，不逐点看 |

共1+1+2=4。安全跳过的理由是包围盒确实包住所有后代：不相交则整棵无解，完全包含则每项都合法，部分相交才需要深入。若包围盒在插入后没更新，这个剪枝就不再安全。

若要求报告四个坐标，右子树即使完全包含，也必须把其中两个点输出，至少再付2步。一般输出k项有$\Omega(k)$成本。节点摘要能常数回答“这段一共有多少”，不会常数吐出任意多条数据。kd树的最坏查询也可能访问许多节点，不能因为小例里跳了一棵就声称所有矩形查询都$O(\log n)$。

## 接线总价最低，与从源点出发路程最短

用能区分两种目标的三角形：A—B权2，A—C权3，B—C权2。

```text
      A
    2/ \3
    B---C
      2
```

最小生成树只需连接全部顶点，总边价最小。Kruskal按权排序：先选A—B2，分量变`{A,B},{C}`；再选B—C2，连成一棵树，总价4；A—C3加入会形成环，跳过。

A作为源的最短路却应保留A—B2、A—C3，距离分别2、3，总边价5。若走MST到C，要A→B→C花4，比直接3长。MST优化“一次性买下哪些边”，最短路树优化“从指定源到每个点怎样走”，两个目标不同，不能只看它们都画成树。

权互异是MST唯一的充分条件；有重复却未必不唯一。例如图本来就是一条两边的链，两边都权1，也只有这一棵生成树。回答“唯一吗”要给能区分的结构，不能把充分条件误读成必要条件。

## 数据流的第3大：保留集合和堆数组都画出来

输入依次4、9、1、7、2、10，要求读满3项后随时报告第3大，重复值按记录计名次。保留容量3的小根堆，根是当前保留的前三大中的最小值，也就是第3大。普通存全部再排序可正确但空间随流增长，反复排序也浪费。

数组按完全树层序保存，根在下标0；以下是一种合法的实际堆状态：

| 新值 | 动作 | 堆数组（不是排序数组） | 第3大 |
|---:|---|---|---|
| 4 | 入堆 | `[4]` | 未满3项 |
| 9 | 入堆，无须上滤 | `[4,9]` | 未满 |
| 1 | 入堆后与4交换上滤 | `[1,9,4]` | 1 |
| 7 | 替换根1得`[7,9,4]`，与较小孩子4换 | `[4,9,7]` | 4 |
| 2 | 不大于根4，丢弃 | `[4,9,7]` | 4 |
| 10 | 替换根4得`[10,9,7]`，与7换 | `[7,9,10]` | 7 |

第4步后堆是根4、左9、右7，父子关系合法，但数组没有排序。要输出前三名的降序顺序，需另处理，不能直接打印堆数组。

不变量是堆中恰好保存已读前缀最大的3条记录。新项不大于根时，已经有3项不小于它，它不会进入前三；较大时，旧根是这4个候选里该被淘汰的最小项。丢掉的项未来也不会重新变成历史前缀的前三，因为未来只会增加更大候选，不会删掉已有项。若题目改成滑动窗口、旧项会过期，这一保留规则就不够了。

对正整数k，每项$O(\log(k+1))$，整个n项流$O(n\log(k+1))$、辅助空间$O(k)$。写k+1是为了包含k=1：维护最大值仍需逐项看，整体$\Theta(n)$。k=0应拒绝，未读满k项应报告未就绪；一边说流式只占k空间、一边另存全体输入，会违背自己的空间承诺。

## 同一张图，BFS求的是边数，Dijkstra求的是权和

有向边S→T权10，S→A权1，A→B权1，B→T权1。BFS第一次从S就发现T，按最少边数取直接边；Dijkstra不能把“第一次发现”当距离定值。

| Dijkstra确定的点 | 松弛以后`dist[A],dist[B],dist[T]` | T的前驱 |
|---|---|---|
| 初始S为0 | `∞,∞,∞` | 无 |
| 处理S | `1,∞,10` | S |
| 处理最小候选A1 | `1,2,10` | S |
| 处理最小候选B2 | `1,2,3` | 改为B |
| 处理T3 | 终止，路径S→A→B→T | B |

堆里如果还留着早先的T10，懒删除版弹到它时应发现10不等于当前dist[T]=3并丢弃，不能再次当最终距离覆盖3。维护一条记录/顶点的decrease-key堆与允许多份旧记录的懒堆，内存、时间口径也不同。

若所有边权都为1，最小权和就是最少边数，BFS每点每边常数处理，O(V+E)更简单。

### 只有0、1边权时，双端队列如何代替堆

这是普通BFS的一个扩展。取有向边S→A权1、S→B权0、B→A权0、A→T权1，按上述顺序扫描S的邻边。最短路应为S→B→A→T，权和1；若把第一次发现A时的距离1当作定值，就会得到错误的2。

队列保存`(候选距离,顶点)`，队头写在左。只有严格改善dist时入队；经0边得到同层距离，放队头，经1边得到下一层距离，放队尾。旧候选出队时核对是否过期。

|出队与处理|距离变化|处理后的双端队列|
|---|---|---|
|初始化|dist[S]=0，其余∞|[(0,S)]|
|S|A改1先放尾；B改0再放头|[(0,B),(1,A)]|
|B|经0边把A从1改0，放头|[(0,A),(1,A)]|
|A的0候选|T从∞改1，放尾|[(1,A),(1,T)]|
|A的1候选|1≠当前dist[A]=0，过期，跳过|[(1,T)]|
|T|距离1确定，无出边|[]|

```python
from collections import deque

def zero_one_bfs(graph, source):
    n = len(graph)
    if not 0 <= source < n:
        raise ValueError("源点越界")
    if any(w not in (0, 1) for edges in graph for _, w in edges):
        raise ValueError("边权必须为0或1")
    dist = [float("inf")] * n
    dist[source] = 0
    queue = deque([(0, source)])
    while queue:
        d, u = queue.popleft()
        if d != dist[u]:
            continue
        for v, w in graph[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                if w == 0:
                    queue.appendleft((nd, v))
                else:
                    queue.append((nd, v))
    return dist
```

图以0到n−1为顶点下标，邻接表中的端点也须合法。为何能不用堆？丢弃过期项后，候选按距离非降；处理距离d时，队里只会剩d和d+1两层。新0边仍为d，插到前面；新1边为d+1，插到后面，都保持次序。因而每个未过期出队项都与Dijkstra一样取到当前最小距离，该点的距离随后不会再改善。每点的出边只在这次定值时扫描一次，每条边最多触发一次入队；连同过期项的弹出，总O(V+E)。非负0边可有环，但相等距离不再次入队，所以不会沿0环无限重复。

若权值变成0、2、7，新候选不再只有相邻两层，同样的头尾规则不能保持距离次序，应换回适合一般非负权的最小堆。

## 再做五题，先写判断依据

1. `ABCA→ACBA`只允许插删，预算2。给具体操作，并说明预算1为何不行。
2. 有人承诺：任意n个互异实数，只用两项比较，最坏不超过3n次。怎样用下界否定它对所有n成立？
3. 向量`[1,3,5,7]`在秩1插2，未扩容。原下标2的物理格现在装什么？保存“指向原5”的旧迭代器能否照用？
4. 随机快排对固定数组的内部随机轴取期望为$O(n\log n)$，是否保证每次运行都如此？
5. 有序数组允许任意点修改，同时求区间和与第一个≥x。一棵只存sum的线段树够不够？

解答：

1. 删原串下标2的C，得到ABA；在首A后插C，得到ACBA，共2步。长度相同、串不同，不可能只用一次插或删，因为任何一次都会改变长度；因此预算1不行。等价地LCS长3，距离$4+4-2\times3=2$。
2. 比较树至少n!叶，最坏深度至少$\log_2(n!)$。取后半至少n/2项，每项不小于n/2，得粗下界$(n/2)\log_2(n/2)$；对足够大n（如偶数n>128）已经超过3n。这里不追求最小矛盾规模。整数位操作不属于“只比较”模型，不能把同一下界套在计数排序上。
3. 底层格子模型中结果`[1,2,3,5,7]`，原下标2的格装3，原5移到下标3。`std::vector`插入点及其后的旧迭代器、引用会失效，不能通过旧句柄读取来“验证仍可读”；链表插入新节点通常保持其他未删节点的身份。物理地址、合法生命期和逻辑身份需要分别判断。
4. 不保证。连续选极端轴仍可能平方；期望是对每一固定输入的内部随机选择平均，不必假设输入本身随机。若实现固定选首项，则没有这份内部随机模型，不能借用同一个期望证明。
5. 任意修改可能破坏全局有序，原二分前提就不在了。只存sum也不能判断某区间是否含≥x：`[1,9]`与`[5,5]`和都10，对阈值8却不同。需额外max摘要才能向左优先寻找满足阈值的位置；区间和仍由sum回答。若修改保证始终有序，可另对原数组二分，但应说明维护这份保证的方式。
