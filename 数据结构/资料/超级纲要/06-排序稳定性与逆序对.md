# 排序时，除了大小次序还在保留什么

同一班同学先按姓名排好，再按成绩从高到低排。若同分学生仍保持原来的姓名顺序，第二次排序就是稳定的。为看出相等值的身份，本章把记录写成`(关键码,标签)`，比较时只比较关键码。

稳定性讨论的是相等关键码的相对顺序，不是算法每次运行结果是否一致，也不是排序有没有越界。原地排序通常指只用常数数量或很少的额外存储；它同稳定性也是两个指标，不能混为一谈。

## 例1：冒泡排序，为什么相等时不交换

给`[(3,A),(1,B),(3,C),(2,D)]`升序排序。第一趟从左向右比较相邻项：3A与1B交换，得到`1B,3A,3C,2D`；3A与3C相等，不交换；3C与2D交换，得到`1B,3A,2D,3C`。最大值3C到了末尾。

第二趟只需处理前三项：1B与3A不动，3A与2D交换，得`1B,2D,3A,3C`。第三趟没有交换，可以提前结束。两个3仍然是A在C之前。

若仅在左项严格大于右项时交换，相等的两项不可能直接越过彼此。相对顺序要改变就必须在某次相邻交换中交叉，而这次交换不会发生，所以算法稳定。若条件写成大于等于，相等项会被交换，稳定性就丢了。

每一趟把当前未排前缀中的最大项推到末尾，证明不变式可写为“最后k项已经处在最终位置”。普通固定趟数版本比较`(n−1)+(n−2)+…+1`次，最好与最坏均Θ(n²)；记录一趟是否交换的版本，已排好输入一趟即可，最好Θ(n)。这些是不同版本，不能不看代码就说冒泡最好一定线性。

还能记录最后一次交换的位置，下一趟只扫描它以前的区域，因为后缀已无逆序。这会改善部分输入，却不改变最坏平方界。

## 例2：插入排序，把新牌插到左侧有序区

数组`[4,2,3,1]`，先认为前1项`[4]`已排序。拿出2，4右移，2放入首位，得`[2,4,3,1]`；拿出3，4右移，3放在2后，得`[2,3,4,1]`；拿出1，4、3、2依次右移，1放在首位，完成。

```python
def insertion_sort(a):
    for i in range(1, len(a)):
        x = a[i]
        j = i
        while j > 0 and a[j-1] > x:
            a[j] = a[j-1]
            j -= 1
        a[j] = x
```

每轮开始前，`a[0:i]`已经有序，并含原前i项的同一批元素。内层将比x大的项右移，空位最后停在所有≤x的项之后。等值旧项不会被跨越，故稳定。若条件改为`>=x`，新的等值项会插到旧项前面，稳定性就变了。

已排好输入，内层每次立即停止，时间Θ(n)；严格倒序，移动1+2+…+(n−1)项，时间Θ(n²)。可以二分找到插入位置，将比较次数减到O(n log n)，但数组搬移仍可能Θ(n²)。减少比较不等于减少移动。

## 逆序对把“离有序还有多远”变成整数

逆序对是下标i<j、数值a[i]>a[j]的一对元素。`[4,2,3,1]`的逆序对有(4,2)、(4,3)、(4,1)、(2,1)、(3,1)，共5对。相等元素不算逆序。

一次交换相邻且逆序的两个元素，恰好消除它们之间的1个逆序，不改变它们与其他元素组成的逆序总数。因此只靠相邻逆序交换排好数组，交换次数正好等于初始逆序数I。

插入排序每右移一个比x大的旧元素，对应原来一对“旧元素在前且比x大”的逆序。总移动数恰好I；加上每项的扫描和放回，成本Θ(n+I)。这个表达式解释了它为何适合接近有序的输入，也解释了随机互异排列中平均Θ(n²)：每一对元素逆序概率1/2，共n(n−1)/2对，期望I=n(n−1)/4。

## 例3：归并，一边排序一边统计逆序

两个已经有序的序列L=`[2,5,8]`、R=`[1,3,7]`。比较两端未取出的最小项：先取1，此时L的2、5、8都大于1，新增3个跨区逆序；再取2，没有新增；取3时L还剩5、8，新增2个；取5无新增；取7时L剩8，新增1个；最后取8。

归并输出`[1,2,3,5,7,8]`，跨区逆序共6。因为L有序，当L[i]>R[j]时，L[i]以及它后面的每一项都大于R[j]，可以一次增加`len(L)-i`，无需逐项配对。相等时先取左侧，既保持稳定，也不会把相等值算进逆序。

递归把原数组切成左右两半，逆序对分为左内部、右内部、跨左右三类，彼此不重叠且覆盖全部。递归统计前两类，归并统计第三类，总时间Θ(n log n)，额外数组O(n)。n很大时逆序数最多n(n−1)/2，计数类型要够宽，即使每个元素本身只需32位，计数也可能需要64位。

归并排序的稳定性也能归纳：左右各自稳定；合并相等值时左先右后，原来位于左半的等值元素本来就在右半之前，所以不会跨越。只说“归并天然稳定”不够，实际比较分支必须采用相应规则。

## 例4：选择排序，“取最后一个最大值”仍可能不稳定

选择排序每轮在未排区找最大项，与未排区末项交换。即使在相等最大项中选最后一个，也不能保证稳定。考虑`[(2,A),(1,B),(2,C),(1,D)]`。

第一轮选最后一个最大项2C，与末项1D交换，得到`2A,1B,1D,2C`。第二轮在前三项里选最大2A，与1D交换，得到`1D,1B,2A,2C`。两个关键码1的记录已经从B在D前变成D在B前。最大项的等值选择规则没有阻止另一个关键码的记录被远距离交换越过。

若改成取出选中项，再把中间项整体平移，最后放到目标位置，可以做稳定的选择过程，但移动成本会改变。链表中也可通过摘下节点再接入目标位置实现不同的稳定版本。判断稳定性要跟着具体动作走，不能只跟算法名字走。

选择排序即使输入已排序，仍需扫描每个未排区找最大，比较次数Θ(n²)；交换通常只有O(n)次。若元素交换特别贵而比较便宜，它可能有自己的使用理由，但大型一般排序通常更偏向其他方法。

## 什么时候用哪一种

小数组、接近有序、插入到已有序列：插入排序常易实现且能利用较少逆序。需要稳定且能接受辅助数组：归并排序有可靠的n log n最坏界。需要理解相邻交换与逆序：冒泡是清楚的教学模型。若只要最小的k项或第k项，完整排序可能做了超出需求的工作，18与20章会介绍堆与选择。

比较排序还存在Ω(n log n)最坏下界，但它不适用于所有输入限制。计数排序对小整数键可用额外范围空间换时间；位图甚至只保存是否出现，不能直接替代带重复计数与记录标签的稳定排序。先看问题允许读取哪些信息，再谈下界。

## 相邻交换的逆序变化，为什么恰好只有一对

相邻位置放x>y，交换为y,x。二者之间的逆序消失。对左侧任意z，它与x、y的两次比较总贡献只与数值有关，不受x、y内部顺序影响；右侧同理。因为中间没有第三项，不会出现其他关系变化，所以逆序总数恰减1。若交换不相邻，就可能一次消除或新增许多逆序，不能继续把交换数等同初始I。

例如[3,2,1]有3个逆序，直接交换首尾便得到[1,2,3]，只用1次任意交换。冒泡需要3次相邻逆序交换。两种“交换次数最少”的问题允许动作不同，因此答案不同。28章的置换环n−c下界适用于任意两位置交换，而不是相邻交换。

## 归并的循环不变式可以写到每个指针

设左右子列L、R已排好，i、j指向尚未取出的首项，输出前缀B已排序且恰含两列中已经取出的元素。比较L[i]与R[j]，较小者不大于所有尚未取出的元素，因此接到B尾仍有序。取完一项只前进对应指针，元素不会重复或丢失。某列耗尽后，另一列剩余本就有序，直接接上。

统计逆序时还要加一句：当前累计值恰好等于已输出右侧元素与尚未输出左侧元素之间，在它们被取出时确认的跨区逆序总数。若取R[j]且R[j]<L[i]，新增L剩余数量，所有这些对都会且只会在此时计一次。若取L[i]，不新增，因为尚未输出的右侧元素均不小于它。

## 多关键字排序，稳定性的用途可以直接看见

学生记录为(班级,成绩,姓名)。先按姓名排序，再稳定地按成绩排序，再稳定地按班级排序，最终以班级为第一关键字、成绩为第二、姓名为第三。后一次稳定排序保留相同新关键字内部已经排好的旧顺序，所以应从最低优先级开始。

若先按班级，再稳定按成绩，最终第一关键字会变成成绩，而非原先班级。稳定性保存的是等值组里的旧次序，不会阻止后一次排序把不同新关键字的记录跨班移动。把三条记录写出来就能检验：甲班90、乙班80、甲班70，最后按成绩全局排序会混开班级。

如果语言排序支持比较器直接比较元组，也可以一次按(班级,成绩,姓名)排序；若比较器在相等关键字上又引入了与原顺序无关的判定，就要重新看它是否满足严格弱序等要求。比较函数自相矛盾，例如同时认为a<b、b<c、c<a，会让排序的基本假设失效。

## 随机排列的平均逆序数，逐对算最清楚

n个互异元素均匀随机排列，给任意一对数x<y，x在y前与y在x前各一半。为这对定义指标X，逆序取1，否则0，期望1/2。全体逆序数是所有n(n−1)/2个指标之和，期望为n(n−1)/4。各对指标并不相互独立，但线性期望不需要独立。

因此稳定插入排序的平均移动数为二次级，尽管它在有序输入上线性。随机输入假设只用于这个平均结论，最坏平方与近有序Θ(n+I)是另外两种描述。若现实数据本来由昨天的排序结果局部修改而来，均匀随机排列未必是合理模型。

## 每个输出记录也需要被读取

即使输入已经有序，要确认并输出全部记录，通常仍需线性遍历。最好时间可以线性，不可能仅因没有交换就把整个排序检查叫零成本。

## 练习与答案

**练习1。** 给`[3,1,2,1]`列出所有逆序对，并预测稳定插入排序的元素右移总次数。

解答：3与后面的1、2、1组成3对；第一个1与后面不构成逆序；2与最后的1组成1对，共4。插入第一个1时移3一次；插入2时移3一次；插入最后1时移3、2两次，共4次。两个1因严格大于时才移动，原先的1仍在后来的1前面。比较次数还包括发现无需继续移动的那一次，因此不必恰好等于4。

**练习2。** 归并L=`[1,3,3]`和R=`[2,3]`，跨区逆序多少？相等时取右侧会发生什么？

解答：取1不增；取2时L剩3、3，增2；以后全是相等3，不新增逆序，答案2。若相等时先取右侧，数值排序依然正确，但R里的3会越过L里的3，失去稳定性。若统计代码把“右侧被取出”一律视为产生逆序，还会把相等项误算，必须把严格大小与相等分开。

**练习3。** 对n项互异数组，逆序对为0能否推出已升序？I很小能否推出每个元素离最终位置都很近？

解答：I=0意味着任意i<j都有a[i]<a[j]，因此升序。I小能约束总的错位，但不保证每一项距离都小。例如`[2,3,4,5,1]`只有4个逆序，末项1却需要向左走4格。说“几乎有序”之前应固定度量，逆序数、最大位移与无序段长度并非同一指标。
