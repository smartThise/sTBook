# 图基础：先记录访问过谁，再沿边走

## 表示方式决定很多成本

邻接矩阵用 Θ(V²) 空间，查一条指定边 O(1)，遍历某点邻居需 O(V)；邻接表用 Θ(V+E) 空间，遍历邻居与度数相关。无向图的边通常存两次，所以遍历总邻接项是2E，仍为 O(E)。自环、重边和有向性要在输入约定里写清。

## BFS 按距离一层一层扩张

从源点入队时立即标记已发现，弹出后扫描邻居，未发现的设距离加一、记录父节点并入队。必须在入队时标记，否则同一节点可能被多条边重复加入。无权图或等权图中，先发现的路径就是最少边数路径；一般带权图不能这样直接算最短路。

对 A-B、A-C、B-D、C-D，BFS 从 A 得距离0、1、1、2；D 第一次由 B 或 C 发现都可得到最短距离，父树可能不同。用邻接表，时间 O(V+E)，队列最坏 O(V)。不连通图要从每个尚未访问点重新启动，得到森林。

## DFS 记录“进入”和“退出”

DFS 沿一条路深入，走不下去才返回。发现时间与完成时间可帮助判断祖先关系和边类型。有向图中遇到仍在递归栈内的点，说明存在环；仅“访问过”还不够，因为对已完成节点的边未必构成当前回路。

DAG 的拓扑排序可用入度队列：初始压入全部入度0点，删除它们及出边，使新入度0点入队；若输出少于 V，说明有环。也可用 DFS 完成次序逆序，但同样需要检测环。

## 无向图的 low 值在说什么

disc[u] 是首次发现时间；low[u] 是 u 的子树通过树边下行、再至多一条回边能到达的最早祖先时间。非根 u 若存在孩子 v 满足 low[v]≥disc[u]，u 是割点；根要单独判断是否至少有两个 DFS 孩子。树边(u,v)若 low[v]>disc[u]，它是桥。≥ 和 > 不能交换。

用边栈在 low[v]≥disc[u] 时弹出相应边，可得到点双连通分量。无向图需要排除返回父边，但有重边时不能简单排除所有“指向父节点”的边，应按边 ID 区分。

**自测。** DFS 树根只有一个孩子，但孩子下面很多点，根是否一定是割点？答：不是；删根后其余节点仍可能都在那一棵子树内连通。根的判断规则与非根不同。
