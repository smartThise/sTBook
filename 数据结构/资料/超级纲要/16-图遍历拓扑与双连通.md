# 图：遍历、拓扑排序与双连通

图（graph）$G = (V, E)$由顶点与联边组成——地图上的城市与道路、课程与先修关系、任务与依赖，都是图。前几章的树其实是图的特例（连通无环）；本章从图的表示出发，讲两遍遍历——BFS与DFS——以及它们的三个直接产出：距离与中心（Erdös数）、拓扑排序（依赖调度）、双连通分量与关节点（网络鲁棒性）。第10章的层次遍历，正是本章BFS在树上的特例。

## 图的表示：邻接矩阵与邻接表

**邻接矩阵**：$n \times n$矩阵，`E[i][j]`记录i到j的边（无向图对称）。优点：直观、判断两点是否有边$O(1)$、顶点度数$O(1)$，尤其适用于**稠密图**。缺点：空间$O(n^2)$，与边数无关——平面图（可嵌入平面的图）由Euler公式$n - e + f = 2$可推出$e \le 3n - 6$，空间利用率仅$\approx 1/n$，对**稀疏图**（sparse graph）极不经济。

**邻接表**：每个顶点挂一个邻接顶点列表。空间$O(n + e)$，与实际边数成正比；递增式构造$O(n + e)$；判断u是否为v的邻居需遍历v的表，$O(1 + deg(v))$。折中方案：邻接表+散列表存边——判边期望$O(1)$、空间$O(n+e)$两全。各种图算法共同的底层需求是枚举v的所有邻居（$O(1 + deg(v))$），两种表示都能胜任。

## 广度优先搜索：图的层次遍历

始自顶点s的BFS：访问s；依次访问s所有尚未访问的邻接顶点；再依次访问它们尚未访问的邻居……直到没有新顶点——策略与过程完全等同于第10章树的层次遍历（FIFO队列），且确实构造出原图的一棵**支撑树**（BFS tree）。BFS树有个漂亮的解释：树上每个节点的`dTime`即s到它的**最短距离**（按边数计）——社交网络里的Erdös Number（与Erdös合写过论文者为1，与1合拍过……）与Chow Number（周星驰合作网络：吴孟达为1、葛优经吴倩莲为2）正是BFS距离；对无向图跑一遍BFS，即得图的**离心率**（某点到最远点的距离）、**半径**（最小离心率）、**直径**（最大离心率）与**中心**。

```cpp
template <typename TV, typename TE> void Graph<TV, TE>::BFS( Rank v, Rank& dClock ) {
   Queue<Rank> Q;  status(v) = DISCOVERED;  Q.enqueue( v );  dTime( v ) = dClock++;
   while ( !Q.empty() ) {
      v = Q.dequeue();                       //取出队首顶点v
      for ( Rank u = firstNbr( v ); -1 != u; u = nextNbr( v, u ) )
         if ( UNDISCOVERED == status( u ) ) {       //u尚未被发现
            status( u ) = DISCOVERED;  Q.enqueue( u );
            dTime( u ) = dClock;  type( v, u ) = TREE;  parent( u ) = v;   //树边
         } else
            type( v, u ) = CROSS;                   //跨边
      status( v ) = VISITED;  fTime( v ) = ++fClock;   //v访问完毕
   }
}  //O(n + e)：邻接表下每顶点入队一次、每边至多查两次
```

复杂度$O(n + e)$。每条边在遍历中被归类：发现的边为**树边**（TREE），指向已在队列或已访问顶点的为**跨边**（CROSS）——无向图的BFS里不会出现反向边。

## 深度优先搜索：一条路走到黑

DFS：访问v；若v尚有未访问邻居，任取其一递归DFS；否则回溯；全图遍历时，若还有未访问顶点，任取其一重新启动。对树而言等效于先序遍历；对图则导出一个**DFS森林**。递归实现配`dTime`（发现时间）与`fTime`（访问完毕时间）两个时钟：

```cpp
template <typename TV, typename TE>
void Graph<TV, TE>::DFS( Rank v, Rank& clock ) {
   dTime( v ) = ++clock;  status( v ) = DISCOVERED;
   for ( Rank u = firstNbr( v ); -1 != u; u = nextNbr( v, u ) )
      if ( UNDISCOVERED == status( u ) ) {
         type( v, u ) = TREE;  parent( u ) = v;  DFS( u, clock );
      } else if ( VISITED == status( u ) )
         type( v, u ) = BACKWARD;               //指向自己的祖先：回路存在的证据
      else
         type( v, u ) = ( dTime( v ) < dTime( u ) ) ? FORWARD : CROSS;
   fTime( v ) = ++clock;  status( v ) = VISITED;
}
```

DFS最锋利的副产品是**括号序列**：把dTime记作`(`、fTime记作`)`，整幅图的括号序列中任意两对括号要么完全嵌套、要么完全分离——由此可$O(1)$判定祖先关系（u是v的祖先当且仅当$[dTime(u), fTime(u)]$包含$[dTime(v), fTime(v)]$），并把边精确分为四类：树边TREE、回溯边BACKWARD（指向祖先——**有向图存在回路当且仅当遍历中出现回溯边**）、前向边FORWARD、跨边CROSS。

## 拓扑排序：DAG的线性次序

任务之间有依赖（A须在B之前），求一个不违反任何依赖的执行顺序。依赖图若有环则无解；**有向无环图**（DAG）则必然可解——拓扑排序对应于把DAG的偏序（POSET）扩充为全序（TOSET）。正确性的钥匙：**有限的偏序集必有极值元素**——DAG中必有**零入度**顶点v可作序列起点，且$G \setminus \{v\}$仍是DAG——减而治之：

```cpp
template <typename TV, typename TE> Stack<TV>* Graph<TV, TE>::topoSort( Rank s ) {
   Stack<TV>* S = new Stack<TV>;            //用栈最终逆序输出
   while ( 0 < ( s = zeroInDegree() ) ) {   //策略1：循序输出零入度顶点
      status( s ) = VISITED;
      for ( Rank u = firstNbr( s ); -1 != u; u = nextNbr( s, u ) )
         InDgree( u )--;                    //后继入度减一
      S->push( s );                         //零入度者压栈
   }
   if ( ( Rank ) G.size() > S->size() ) S->push( nullptr );   //残留非空：存在环路
   return S;
}  //O(n^2)；改用反向邻接表+零入度队列，可至O(n+e)
```

残留顶点非空即说明图中有环（所有剩余顶点入度均大于零）。策略二借助DFS：**第k个回溯（fTime）的顶点，恰是拓扑序的倒数第k个**——逆序输出fTime序即得拓扑序；两种策略导出的序列可以不同，但都合法（拓扑排序通常不唯一）。

## 双连通分量与关节点

无向图中删除后使连通性被破坏的顶点称**关节点**（articulation point）；不含关节点的极大连通子图称**双连通分量**（biconnected component）——网络鲁棒性的基本度量：关节点倒下，系统分裂。DFS以$O(n+e)$找出全部关节点，核心是为每个顶点维护**hca**（highest connected ancestor，最高可达祖先）：$hca(u) = \min\{ dTime(w) \mid (u,w) \text{为回溯边或} w = u \}$沿子树取最小。判定规则：

- **树根**是关节点，当且仅当它在DFS森林中有**两个以上**的孩子（各有独立子树，无横跨边相连）；
- **非根u**是关节点，当且仅当存在孩子C，其子树（含C）通过回溯边最高只**回到u或更浅**——即$hca(C) \ge dTime(u)$，该子树与祖先之间没有旁路。

借助hca还能顺带标出每个双连通分量的边界：$hca(C) < dTime(u)$时子树可上溯更高祖先，$u$与C之间恰好切出一个双连通分量。整个算法一遍DFS完成，$O(n + e)$。

## 本章要点

- 邻接矩阵宜稠密（判边$O(1)$、平面图$e \le 3n-6$故稀疏图浪费）；邻接表宜稀疏（$O(n+e)$）；表+散列判边期望$O(1)$两全。
- BFS=队列=层次遍历推广，BFS树给出最短距离（Erdös数、离心率/半径/直径/中心），$O(n+e)$，边分类TREE/CROSS。
- DFS=递归=先序，DFS森林；dTime/fTime括号序列$O(1)$判祖先；边四分类，**回溯边⇔有向回路**。
- 拓扑排序：DAG必有零入度顶点，减而治之；或逆DFS回溯序；残留非空⇔有环。
- 关节点：根（两棵以上孩子）与非根（$hca(C) \ge dTime(u)$）两条判据；双连通分量一遍DFS全部标出。
