# 二分查找：先说清“找哪个边界”

## 找到一个、最左一个、最后一个，三个任务不同

本章采用半开区间 [lo,hi)。找第一个不小于 x 的位置，也叫 lower_bound：左侧全部 <x，右侧全部 ≥x，中间尚未确定。初始 lo=0、hi=n。

```cpp
int lower_bound_index(const std::vector<int>& a, int x) {
    int lo = 0, hi = (int)a.size();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < x) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}
```

若答案等于 n，说明所有元素都小于 x，不能再读 a[n]。判断存在要额外检查 `p<n && a[p]==x`。返回插入位置与返回“某个相等项”不是同一种接口。

例：a=[1,3,3,7]，x=3。先 mid=2，a[2]≥3，hi=2；再 mid=1，hi=1；再 mid=0，lo=1；最后 [1,1)，返回 1。每一步宽度严格缩短，所以不会卡住。

## Fibonacci 与插值查找

若向左和向右的比较成本不同，最优切分不必正好一半，Fibonacci 查找由此有意义。任意固定比例 α∈(0,1) 切分，只要两侧都严格缩小，最坏仍 O(log n)，常数不同。比例若随 n 靠近 0 或 1，则不能继续沿用固定比例结论。

插值查找利用值分布估位置：$m=lo+\lfloor(x-a_{lo})(hi-lo)/(a_{hi}-a_{lo})\rfloor$，需处理分母 0、越界和中间乘法溢出。分布均匀等假设下可很快，畸形分布却可能退化为线性；它没有无条件优于二分的保证。很短的区间中顺序扫描还可能因缓存和分支开销更快，阈值应实测。

## 位图：一个可能值，分配一个 bit

整数范围 [0,U)，令第 x 位表示 x 是否出现。字节索引 x/8，位索引 x%8，用无符号掩码操作。空间 Θ(U) bit；扫描输入 O(n)，若按整个值域输出有序结果，还要 O(U)。所以总时间应写 O(n+U)，不能因为 n 很小就忽略巨大值域。

稀疏集合的校验环可用 dense 与 sparse：x 有效，当 `sparse[x]<size && dense[sparse[x]]==x`；插入同时维护反向关系，清空只令 size=0。它给 O(1) 逻辑重置，不表示底层数组不占 Θ(U) 空间，也不允许在 C++ 中读取从未合法初始化的任意标量来制造未定义行为。

**自测。** 二分代码中把 `hi=mid` 改成 `hi=mid-1` 能否照旧？答：不能；半开边界的不变量随之破坏，可能漏答案。边界和更新公式必须整套设计。
