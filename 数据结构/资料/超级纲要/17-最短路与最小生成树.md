# 最短路径与最小生成树

带权图上的两类经典优化。**最短路径**（shortest path）：从顶点s出发，到每个顶点的最短路径及长度——SPT（最短路径树）；**最小支撑树**（MST）：连通网络上挑选$n-1$条边，让连通保持、总权重最小——运输、电信、VLSI布线的共同模型，也是众多NP难问题的近似解跳板。两者形似（都借优先级队列贪心生长）而质异：前者最小化"路径长度"，后者最小化"边权总和"，答案不可互换。本章依次给出Dijkstra（单源）、Floyd（每对顶点）、Prim与Kruskal（MST）。

## 最短路径树与贪心的通行证

WLOG设每条最短路径唯一，则所有最短路径的并构成一棵树（SPT）。Dijkstra算法赖以成立的两条性质：**最短路径的每个前缀也必是最短路径**（否则把坏的段替换掉，总长更短）；**沿任何最短路径，各节点到起点的最短距离单调递增**（边权非负）。于是从S出发，每次从候选中取出"当前dist最小且未确定"的顶点——它不可能再被绕行改进，可以放心"盖章"；随后用它的边松弛邻居。

## Dijkstra：优先级搜索

教材把Dijkstra统一进图的`pfs()`优先级搜索框架——与Prim共用骨架，只是优先级更新器不同：

```cpp
g->pfs( 0, DijkPU<char, Rank>() );   //从顶点0出发启动Dijkstra
template <typename TV, typename TE> struct DijkPU {    //优先级更新器
   virtual void operator()( Graph<TV, TE>* g, int uk, int v ) {
      if ( UNDISCOVERED == g->status( v ) )             //尚未发现的邻居v
         if ( g->priority( v ) > g->priority( uk ) + g->weight( uk, v ) ) {
            g->priority( v ) = g->priority( uk ) + g->weight( uk, v );   //更新优先级
            g->parent( v ) = uk;                        //更新父节点
         }
   }
};
```

以四顶点图走一遍松弛过程（$S{\to}A{=}10$、$S{\to}B{=}3$、$B{\to}A{=}4$、$A{\to}C{=}2$、$B{\to}C{=}8$）：

![逐步演示：Dijkstra：S/A/B/C的松弛过程](图片/演示-ds17-dijkstra-01.svg)

结果：dist = S:0、B:3、A:7、C:9。复杂度：优先队列实现下$O((n+e)\log n)$；$O(n^2)$的朴素数组版本对稠密图反而更快。**负权边时Dijkstra的贪心失效**（已盖章顶点可能被负权绕行改进）——单源需Bellman-Ford（$O(ne)$，可检出负环）；每对顶点的全源问题另有更省的Floyd。

## Floyd-Warshall：每对顶点

需要所有顶点两两之间的最短距离时，逐点跑Dijkstra要$O(n \cdot (n+e)\log n)$；Floyd-Warshall以动态规划$O(n^3)$、$O(1)$额外空间完成（允许负权、不许负环）。递推只问一件事：**中途点是否经过k**？

$$d^{(k)}[i][j] = \min\left(d^{(k-1)}[i][j],\ d^{(k-1)}[i][k] + d^{(k-1)}[k][j]\right)$$

$d^{(k)}[i][j]$表示"允许途经$\{0..k\}$中顶点"时i到j的最短距离；k一维一维地放开，三轮循环写完即得全表。路径重建借助`next[i][j]`（i出发去j时的下一站）随更新同步维护。

## 最小支撑树：割定理与两个贪心

MST总是存在（支撑树虽多毕竟有限，权重可比），且未必唯一。两个算法共享同一块基石——**割定理**（cut property）：把顶点集分成两部分，横跨割的最轻边必属于某棵MST（否则把它换进树里，总权下降）。

**Prim**（Jarník 1930 / Prim 1957）：从单个顶点出发生长支撑树，每步取**横跨"树内/树外"割**的最轻边、把对应顶点拉进树内。实现与Dijkstra共用`pfs()`框架，优先级更新器换成PrimPU——优先级不再是"到源点的距离"，而是"**到已生长部分的最短边权**"。每次$O(\log n)$，总体$O((n+e)\log n)$。

**Kruskal**（1956）：视角从"顶点生长"换成"边排序"。所有边按权重递增排序，逐边考察——两端点尚不连通则接受，否则舍弃，直至选满$n-1$条。判连通用第09章的散列与并查集思路：find查询、union合并，每次近$O(1)$，总体$O(e\log e)$（排序主导）。Kruskal的正确性同样出自割定理：每次被接受的边恰是当时某个割的最轻边。

**延伸**：这一支算法家族历史久长——Boruvka（1926）、Jarník（1930）、Prim（1957）、Kruskal（1956）、Karger-Klein-Tarjan（1995，线性期望）、Chazelle（2000，软堆$O(e\alpha(e,n))$）；近亲问题里Proximity Graphs可$O(n\log n)$，而Steiner MST（允许新增Steiner点）则是NP-hard——同族问题的难度可以差一个数量级。

## 本章要点

- SPT：最短路径的前缀也是最短路径；距离沿最短路径单调递增——Dijkstra贪心的通行证。
- Dijkstra＝PFS+DijkPU（priority = 到源距离），$O((n+e)\log n)$；负权失效，Bellman-Ford补位。
- Floyd-Warshall：$d^{(k)}[i][j]=\min(d^{(k-1)}[i][j], d^{(k-1)}[i][k]+d^{(k-1)}[k][j])$，$O(n^3)$、原地滚动，全源最短。
- MST割定理：横跨割的最轻边必在MST中；Prim顶点生长（PrimPU）、Kruskal边排序+并查集判环，分别$O((n+e)\log n)$与$O(e\log e)$。
- 家族谱系从Boruvka到Chazelle；Steiner MST已NP-hard——模型之差，难度天壤。
