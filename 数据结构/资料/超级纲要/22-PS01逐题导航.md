## 1 · 计算工具：算法不一定写在电脑里

算盘、尺规和纸笔都能执行计算。区别在于，它们允许的基本动作不同。算盘可以拨珠，尺规可以画直线、画圆、取交点，纸笔可以逐位写数。一个过程要说清楚，首先要说明输入如何放进去。例如用算盘算 $27+35$，先用十位和个位的珠位表示27，再加3个十和5个一；个位从7加5得到12，要留下2并向十位进1，最后读出62。只有“把数加起来”这句话还不是给执行者的完整步骤。

可以把十进制竖式加法写成程序：从最低位起，把两位数字和进位相加；结果对10取余作为本位，除以10取整作为新进位；移动到高一位，直到两串数字和进位都用完。每次处理一位，长度为 $d$ 的输入需要 $O(d)$ 个这样的逐位动作。

C++把动作写成有精确语法的语句，变量、条件和循环都有规定的含义；自然语言描述更容易夹带“适当处理”之类的空白。反过来，尺规的“取两个圆的交点”是它的原语，在普通电脑里却要另外表示坐标、处理精度、求方程。比较两种算法快慢以前，需要把基本动作放在同一个计算模型里。

可以自己试一个检查：让完全没参与设计的人照步骤算 $99+1$。若他不清楚最后的进位要不要额外写一位，说明描述漏了边界，而不是他“应该懂”。

## 2 · 曹冲称象与刻舟求剑：保存的究竟是什么

曹冲称象需要的量是“大象使船增加的排水重量”。把大象放上船，在船舷记录水线；移走大象，再逐块放石头，直到同一条水线重新与水面重合。在船本身、船中其他载荷、水的密度等条件保持一致时，相同吃水意味着相同排水体积，因此石头总重量等于大象重量。最后称石头就把一个难称的大物体转成了若干容易称的小物体。

这里的记号标在船上有用，是因为水线要表示船相对水面的吃水状态。刻舟求剑要找的却是剑相对河床的位置；船移动后，刻线跟着船走，剑没有跟着走。记号保存了“剑落水时相对船的位置”，而人想恢复“现在相对河床的位置”，中间缺了船的位移。若剑在落水后还受水流影响，甚至连固定的河床位置也要另作假设。

用算法语言说，输入信息必须足以确定输出。设落剑时船在地面坐标 $x_0$，记号相对船的位置为 $r$，则剑的初始地面坐标是 $x_0+r$。船后来到 $x_1$，拿同一记号推断的位置是 $x_1+r$，误差正是 $x_1-x_0$。把坐标写出来，就能指出错误发生在哪一步。

这个题也提醒我们：程序可以按预定步骤顺利结束，却算错问题。有穷性保证会结束，正确性还需要输入、模型和推理都对。

## 3 · 死循环：局部能查，万能检查器做不出来

先看最常见的一类错误：

```cpp
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;
    if (a[mid] < target) lo = mid; // 长度为1时不再缩短
    else hi = mid;
}
```

若 `lo=4, hi=5` 且 `a[4]<target`，就有 `mid=4`，更新后还是 `[4,5)`，此后完全重复。修正通常是 `lo=mid+1`，但仍要检查这是否符合想要的返回语义。调试时把 `lo,hi,mid` 打印出来，比一直盯着循环体更容易看见状态没变。

证明一个循环终止，可以找“非负整数、每轮严格减少”的量。这里取 $hi-lo$。它不能降到负数，每次又至少减1，因此轮数有限。只写“区间变小”不够，要检查每一条分支，特别是长度0和1。机器整数溢出还可能让本应下降的量突然变负或绕回去，实际程序必须另查类型。

为什么不能写一个检查任意程序的万能算法？假设存在 `halts(P,x)`，能判断程序P在输入x上是否结束。构造程序D：输入程序P，若 `halts(P,P)` 说会结束，D就永远循环；若说不会结束，D立刻结束。再问D在输入自己时会怎样。判断说会结束，D偏不结束；判断说不结束，D偏结束，产生矛盾。因此这个假设不成立。

这不妨碍我们检查具体程序、有限状态程序，或要求循环带下降量的受限语言。正确的实践是组合使用不变量、边界测试、超时和审查；超时发现“这次没在限定时间结束”，本身不能证明永远不结束。

## 4 · Failstone：别因为长得像冰雹序列，就停止证明

原题递归在 p=q 时返回1；否则变换参数并把返回值加1。下面明确讨论正整数 $p,q\ge1$，并假定算术精确、没有溢出。若允许 p=0,q>0，奇数q时会原样重复 `(0,q)`，结论就变了。“自然数”是否包含0必须先约定。

可以不用深递归，而是直接数经过多少个状态：

```python
def failstone(p, q):
    if p <= 0 or q <= 0:
        raise ValueError("本实现只接收正整数")
    states = 1
    while p != q:
        if p > q:
            p, q = p - q, p
        elif q % 2:
            p = 2 * p
        else:
            q //= 2
        states += 1
    return states
```

例如从 `(1,3)` 开始，依次得到 `(2,3)`、`(4,3)`、`(1,4)`、`(1,2)`、`(1,1)`。共有6个状态，所以返回6。要把末尾的基础情形也数一次；只数变换次数会少1。

困难在于，单步最大值不总下降：`(2,3)` 变成 `(4,3)` 时还变大了。我们把有限的几步捆成一组。若 p<q 且q为偶数，减半q后，新的最大值小于原q。若 p<q 且q为奇数，就不断将p加倍。若中途相等立即结束；否则一定能到某个 $p^*<q<2p^*$，因为正整数反复加倍会超过固定q，而且奇数q不可能等于偶数 $2p^*$。

接下来三步是

$$
(p^*,q)\longrightarrow(2p^*,q)
\longrightarrow(2p^*-q,2p^*)
\longrightarrow(2p^*-q,p^*).
$$

最后一步合法，因为第二项 $2p^*$ 是偶数，且 $0<2p^*-q<p^*$。这组变换后两项都小于原来的q。若起初 p>q，先走一步得到 `(p-q,p)`，再进入刚才的小项在前的情形，后续一组同样让最大值降到原p以下。

因此，每组都在有限步内结束，并让正整数最大值严格下降；这样的组不可能无限多。这就证明了原过程对正整数一定结束。它与尚未普遍解决的另一道递推问题相似，并不能把那个问题的未知状态搬过来。

## 5 · 几何分布：要数到第一次成功为止

每轮独立，成功概率固定为p，直到第一次成功的轮数记为K，且成功那轮也计数。那么

$$
P(K=k)=(1-p)^{k-1}p,\quad k=1,2,\ldots
$$

前 $k-1$ 轮失败，第k轮成功，两部分概率相乘。求期望有个很省事的办法：先做一轮，用掉1；若失败，以后仍然面对同样的问题。因此 $E[K]=1+(1-p)E[K]$，移项得 $E[K]=1/p$。

例如独立地掷公平硬币直到第一次正面，平均需要2次；成功率为0.2的独立尝试平均需要5次。平均5次不表示第五次一定成功，前20次都失败的概率仍是 $0.8^{20}>0$。

符合模型的计算例子是：从固定集合均匀独立抽样，直到抽到某个目标；或者每轮独立选择随机候选，命中合法集合的比例恒为p。网络重试常有服务器状态变化、限流、相关故障，不能只因为“也在重试”就套几何分布。若允许最多重试m次，随机变量还变成了截断版本，期望也要重新算。

## 6 · 分解大整数：先忠于题目的蛮力算法

原流程依次试素数2、3、5、7……；找到因子就除掉，直到剩余数为1。这里没有写“试到平方根便停止”，所以不能在分析中悄悄加上这项优化。

最坏例子可以取接近 $10^{100}$ 的素数N。每个小于N的候选素数都试不出因子，直到N本身才整除成功，测试量约为素数计数函数 $\pi(N)$。用素数分布的渐近估计 $\pi(N)\sim N/\ln N$，在这个量级约为 $10^{100}/(100\ln10)\approx4.34\times10^{97}$ 次。这个数只是数量级估计，不能当成对某一个具体N的精确素数数量；光生成所有候选素数还另有成本。

最好让待分解数是很小素数的幂。取 $N=2^k$，每次都能除以2，约经过 $k=\log_2N$ 次成功除法。$10^{100}$ 附近的2的幂需要约332或333次，具体取决于选的是哪一个幂。“同样约100位十进制数字”，计算量能相差几十个数量级。

若采用平方根停止并在最后输出剩余因子的改进版，素数输入只需试到 $\sqrt N$。那是另一个更好的算法，回答时应先分析原流程，再单独说明改进。大整数除法本身也不必是单位成本；若按位模型收费，还要乘上相应位长的运算成本。

## 7 · 图灵机递减：借位时到底改了哪几位

设纸带上是最高位在左的二进制正整数，读头先移到最低位。做减1时：读到0就把它改成1并向左，继续借位；读到第一个1就把它改成0，借位结束。之后根据题目约定删去多余前导0、复位读头、进入停机状态。

用 `1000` 减1逐步看：最低位0改1得到 `1001`，再向左把0改1得到 `1011`，再改一位成 `1111`，最后把最左的1改0，得到 `0111`，去掉前导0即 `111`。中间的 `1111` 不是结果，因为“仍在借位”的状态还没有结束。

`1011` 减1只改最低位1为0，得到 `1010`；`1` 减1得到0。输入0若属于允许集合，不能继续向左无限找1，应该单独输出边界错误或按明确规定返回0。减法所需改写次数等于尾部连续0的数量再加1，最坏与数字位数成正比。

图灵机的状态名不是装饰。至少要区分“去最低位”“借位”“返回起始处”“结束”，否则同一个符号1在不同阶段应执行什么动作就说不清。复位读头产生的移动也属于时间成本。

## 8 · 允许读头原地停留，会不会多出一种计算能力

只允许L和R时，每走一步位置的奇偶性都会改变。若读头最后回到起点，向左和向右的步数相等，移动总次数是两者之和，因此为偶数。这是对位移计数的结论，不是说程序中所有操作都天然成双。

加入N表示头不移动。设某条可达转移在读到某符号、处于某状态时，既不改符号也不改状态，且动作为N，那么执行后整个配置与执行前完全相同。确定性的机器下一步还会选同一转移，于是永久重复。要让一条有效计算路径最终结束，这类转移必须改变符号或状态，或者本身就是停机规则。

时间应该按转移次数数，而不是只数头移动了多远。连续100次改状态但不移动仍做了100步，不能算零时间。N也能由原模型模拟：先向一侧移动，进入一个记住待返回状态的临时状态，再向另一侧移回；邻格读到什么就原样写回。这样只增加常数倍转移，没有改变哪些问题可计算。

这项模拟说明模型的可计算能力相同，但不保证逐步时间完全相同。比较复杂度时要保留“至多常数倍模拟开销”这一层说明。

## 9 · RAM：用加减和跳转实现乘除

RAM模型通常用一组可寻址寄存器保存数，用指令修改寄存器，用条件跳转控制执行位置。图灵机一次只读写头下的格子；RAM可以按地址访问寄存器，所以它更接近我们写数组程序时的抽象。两者的时间度量还取决于是否限制字长，不能只凭外形决定。

非负整数乘法可以用“较小问题变一半”的办法。计算 $13\times11$：11的二进制是1011，于是 $13\times11=13\times(8+2+1)=104+26+13=143$。程序每轮看乘数最低位，若为1就累加当前被乘数；然后被乘数翻倍、乘数整除2。

```python
def multiply(a, b):
    ans = 0
    while b:
        if b % 2:
            ans += a
        a *= 2
        b //= 2
    return ans
```

若这些单字加法、移位和测试都算常数，轮数是 $O(\log(b+1))$。若数能任意长，加法和移位也要按实际位数收费，不能照搬单位字模型的结论。

向下取整除法可以先把除数b倍增成 $b,2b,4b,\ldots$，直到下一倍超过a，再从大到小决定是否减去这一倍。例如 $37/5$：可用20、10、5，依次减去20余17，减10余7，减5余2，商为 4+2+1=7，余数2。最后核对 $37=5\times7+2$，且 $0\le2<5$。

向上取整的商在余数不为0时比向下取整大1，因此 $\lceil a/b\rceil=\lfloor a/b\rfloor+[a\bmod b\ne0]$。b必须为正。`(a+b-1)/b` 虽常见，但定长整数里 `a+b-1` 可能先溢出。

C++还有类型、对象生命周期、异常、模板和库接口等语言规则。RAM的一个抽象寄存器不能直接等同为任意一个C++对象；分析代码时需要说明哪些语言操作被映射成什么成本。

## 10 · 小o与小ω：比“同阶”更强的判断

$f(n)=o(g(n))$ 表示 $f/g\to0$，即f相对g越来越可忽略；$f(n)=\omega(g(n))$ 表示 $f/g\to\infty$。这里先假定g最终为正。大O只要求比值最终有一个固定上界，小o则要求不管选多小的正上界，最终都能低于它。

例如 $n/(n\log n)=1/\log n\to0$，所以 $n=o(n\log n)$，也就是 $n\log n=\omega(n)$。但 $3n$ 与n的比值恒为3，所以 $3n=\Theta(n)$，却不是 $o(n)$。

再看一个容易误判的例子：$n/1000$ 在很多输入上比n小很多，但二者仍同阶，因为“1000”是固定常数。反过来 $n/\log n$ 与n的相对差别会随n增长，前者才是 $o(n)$。这些符号描述极限趋势，不表示某个小规模输入上哪一个实际更快。

## 11 · 乘法、除法能不能当$O(1)$

若课程明定“机器字内的整数乘除”属于RAM原语，分析时就可以算一次基本操作。但这个约定含有一个前提：操作数能放进规定字长，而且不把任意大整数悄悄塞进一个寄存器。

用只支持加减、移位的指令实现乘法，第9题展示的算法要按乘数位数做多轮；用小学竖式乘两个L位二进制数，最朴素需要 $O(L^2)$ 个逐位动作。这和“CPU有一条乘法指令”的单位成本说法并不冲突，它们在不同模型里计费。

因此写复杂度报告时可以明确说：“以下n个元素均为固定宽度整数，比较和算术按单位成本计。”若题目让你处理有百万位的数，就必须把位长作为规模的一部分。用一句“乘法都是常数”会抹掉题目真正的难处。

## 12 · 取对数：正向可保留上界，反向只得到多项式关系

原题问的是：由 $T(n)=O(f(n))$，是否有 $\log T(n)=O(\log f(n))$，反向又怎样。先设 $T(n),f(n)\ge1$，且f最终至少为某个大于1的常数；更常见的充分条件是 $f(n)\to\infty$。这样对数非负，分母不会一直为0。

若 $T\le Cf$，两边取对数得到 $\log T\le\log C+\log f$。在 $\log f$ 最终有正下界时，常数 $\log C$ 能被另一个常数倍的 $\log f$ 吸收，所以正向成立。若f恒为1、T恒为2，虽然 $T=O(f)$，但 $\log f=0$、$\log T>0$，就不能写成后一关系。这说明前提不是可省略的装饰。

反向通常不成立。取 $T(n)=n^2,f(n)=n$：有 $\log T=2\log n=O(\log f)$，但 $T/f=n\to\infty$，所以 $T\ne O(f)$。对数把幂次从指数位置拉成了乘法常数，而大O恰好会忽略这个常数。

从 $\log T\le C\log f$ 真正能推出的是 $T\le f^C$，即T受f的某个固定次幂约束；不能擅自把这个幂C改回1。核对方法很简单：每次把两边指数化，看看常数究竟跑到哪里去了。

## 13 · 指数枚举：输出数量本身可能就很大

n个元素的每一个子集都可用长度n的0/1串编码：第i位为1表示取第i项。每位有两个选择，候选共有 $2^n$ 个。枚举n个布尔变量的所有真值赋值、逐一检查所有子集的重量，也都有这层枚举成本。

n从20增加到40时，候选量从约一百万增加到约一万亿；输入只翻倍，候选却平方。这正是先估算复杂度再写PA的理由。若每个候选还要重新扫描n项，时间是 $O(n2^n)$；若用增量维护，单个候选成本可能下降，但候选数本身没有消失。

要区分两个结论：“这个算法枚举了 $2^n$ 个候选”与“这个问题的所有算法都必须指数时间”。前者直接数流程就能证明，后者是问题下界，通常难得多。对于特定子集问题，折半枚举还能把主要枚举规模降到 $2^{n/2}$，这已经足以推翻“只能按原算法那么慢”的断言。

## 14 · 32位、64位无符号整数有几位十进制

正整数x的十进制位数是 $\lfloor\log_{10}x\rfloor+1$。因为d位数恰好落在 $10^{d-1}\le x<10^d$ 之间，两边取对数即可得到这个式子。

w位无符号整数最大值为 $2^w-1$。32位最大值是4294967295，共10位；64位最大值是18446744073709551615，共20位。估算时用 $\log_{10}2\approx0.30103$，32乘它约9.633，64乘它约19.266，分别向下取整再加1。

这里问的是“十进制字符要写几位”，不是“数有多大就需要多少字节”。64位数在机器的定长二进制表示里仍占8字节，而把它打印成十进制文本最多要20个数字字符，若用C字符串还要给末尾零字符留位置。

## 15 · 时限预算：给自己的程序做一个能被反驳的估计

先从题面记下n的上限、时限、内存限额、编译器和允许的库，再写出候选算法的操作量。例如n为20万时，二重循环约 $4\times10^{10}$ 对，排序约 $n\log_2n\approx3.5\times10^6$ 次比较；即使常数有差异，这个数量级对比也足够先淘汰朴素二次方案。

不能把“每秒一亿次”当硬件定律。一次比较可能是两个整数，也可能比较长字符串；访问连续数组和随机追指针的缓存代价也不同。正确做法是在目标环境用与题目相似的数据做小型基准，确认随n增长的趋势，并保留一定余量。

内存也要算。例如两个长度20万的64位数组约占 $2\times200000\times8=3.2\times10^6$ 字节；若递归每层复制数组，或每个元素另建一个带指针的节点，实际占用会增加。记录的是你实际运行的配置和结果，不把本书的示例数字当作OJ实测记录。

## 16 · 典型循环：先给每个位置写“收费项目”

官方《习题解析》1-32中的16段程序已经在第32章逐段展开。这道题练的是数法，建议先遮住答案，把每段程序分成“外层取哪些值”“每个外层值的内层做多少次”“条件判断本身贵不贵”三列。

例如 `for(i=1;i<=n;++i) for(j=1;j<=i;++j)` 的收费是 $1+2+\cdots+n=n(n+1)/2$。把内层改成 `j*=2`，第i轮就只有 $lfloor\log_2 i\rfloor+1$ 次，累计才是 $\Theta(n\log n)$。外层同样写着n轮，并不能决定整体是几次方。

特别留意循环条件中的函数：`while (i < n/G(i))` 每检查一次条件都可能重新计算G。若G本身递归，不能因为它没写在花括号里面就免费。第32章的开方递归例正是把条件成本漏掉后容易答错的题。

## 17 · 分数级数怎样估整数次数

运行次数当然是整数。例如内循环按步长i扫到n，真实次数是 $\lfloor n/i\rfloor$。分析时把它夹住：

$$
\frac ni-1<\left\lfloor\frac ni\right\rfloor\le\frac ni.
$$

对i从1加到n，得到 $nH_n-n<\sum_i\lfloor n/i\rfloor\le nH_n$。上下界只差至多n，而 $nH_n=\Theta(n\log n)$，因此真实整数和也为 $\Theta(n\log n)$。

拿n=5手算，次数为5、2、1、1、1，总计10；分数和为 $5(1+1/2+1/3+1/4+1/5)\approx11.42$。我们没有声称程序做了11.42次操作，只是用一个更容易计算的数给真实次数定界。

## 18 · 调和级数：把一块块矩形放在曲线上

记 $H_n=1+1/2+\cdots+1/n$。函数 $1/x$ 单调下降，所以在区间 $[k,k+1]$ 上，函数面积不超过高度为 $1/k$ 的矩形；把这些区间拼起来，得到

$$
\int_1^{n+1}\frac{dx}{x}\le H_n.
$$

另一方面，从第2项起，每一项 $1/k$ 不超过区间 $[k-1,k]$ 下的面积，所以 $H_n\le1+\int_1^n dx/x$。积分就是自然对数，于是

$$
\ln(n+1)\le H_n\le1+\ln n.
$$

上下都是对数增长，故 $H_n=\Theta(\log n)$。换对数底只乘一个固定常数。若只记住“调和级数发散”还不够：发散表示最终能超过任意常数，这道题还要知道它慢到什么程度。

## 19 · 为什么 $\log(n!)$ 是 $n\log n$ 量级

把乘积取对数：$\log(n!)=\sum_{i=1}^n\log i$。上界很直接，每项至多 $\log n$，所以和至多 $n\log n$。下界只拿后半段，至少有 $\lfloor n/2\rfloor$ 项，每项至少 $\log(n/2)$，因此和至少约 $(n/2)\log(n/2)$。这已经证明了 $\Theta(n\log n)$。

Stirling公式给出更细的近似：

$$
n!\sim\sqrt{2\pi n}(n/e)^n,
\qquad
\ln(n!)=n\ln n-n+\tfrac12\ln(2\pi n)+o(1).
$$

例如n=10时，$\log_2(10!)\approx21.79$。这表示区分10个互异元素的所有排列，二元比较树至少需要足够深，不能用十次左右的比较普遍完成排序。精细近似能估常数；只求渐近阶时，前面的上下夹逼更短，也更不容易记错。

## 20 · 递归空间：数同时没回家的调用，不数一共来过几次

线性递归 `sum(a,n)=sum(a,n-1)+a[n-1]` 在最深处会同时保留n层左右的调用帧。每层若只存固定几个下标、返回地址和局部量，辅助空间是 $\Theta(n)$。把输入数组本身排除以后，这些栈帧仍然是额外空间。

二分求和先算左半，再算右半。递归树总节点仍有 $\Theta(n)$ 个，因此总时间为 $\Theta(n)$；但任一时刻只在一条根到叶的路径上，深度为 $\Theta(\log n)$，辅助空间只有 $\Theta(\log n)$。顺序执行的左右子树不会同时保留各自所有内部调用。

迭代求和只用一个累计值和一个循环下标，空间为 $O(1)$。若每次递归都先复制子数组，再调用函数，复制出的数组可能还没释放，空间就不能只按“每层常数”算了。若并行启动左右递归，也要重新检查同时存活的任务和缓冲。

时间和空间有联系，但不必同阶。二分求和就是时间n、空间$\log n$；缓存所有子问题可能多占空间却大幅省时间。判断时画“某个时刻哪些对象仍活着”，比把递归树所有节点直接相加更可靠。

## 21 · reverse：交换放在递归前后，为什么结果一样

采用闭区间 `[lo,hi]`。当 `lo>=hi` 时不做事；否则交换两端，再反转内部 `[lo+1,hi-1]`。交换的两个位置和内部递归处理的位置不重叠，因此可以调换这两步。

例如 `[1,2,3,4]`：先交换外端得到 `[4,2,3,1]`，再交换内部得到 `[4,3,2,1]`。先做内部则先得到 `[1,3,2,4]`，再换外端，同样得到 `[4,3,2,1]`。这不是“所有两行代码都能交换”，而是这里两步对互不重叠的数据起作用。

每层做一次常数时间交换，规模减2，层数约n/2，所以两种顺序时间都为 $\Theta(n)$。普通递归实现保留 $\Theta(n)$ 层帧。递归放最后时有尾调用形式，某些编译器可能优化；C++不保证一定消去栈帧，因此若必须保证常数辅助空间，明确写双指针循环更稳妥。

## 22 · Master定理：从每层的账单证明，而不是背三行结论

先处理 $T(n)=aT(n/b)+g(n)$，其中 $a\ge1,b>1$ 为常数，基础规模的成本为正常数。为看清结构，先取 $n=b^L$，省掉取整；常用取整版本还需保证递归规模确实下降。记 $d=\log_b a$。

第i层有 $a^i$ 个节点，每个规模 $n/b^i$，本层非递归成本为 $a^ig(n/b^i)$；第L层叶数是 $a^L=n^d$。所以

$$
T(n)=\Theta(n^d)+\sum_{i=0}^{L-1}a^ig(n/b^i).
$$

若 $g(n)=O(n^{d-\varepsilon})$，代入第i层，有 $a^ig(n/b^i)=O(n^{d-\varepsilon}b^{i\varepsilon})$。这是向叶层增长的几何级数，和为 $O(n^d)$，叶层本身又提供 $\Omega(n^d)$，故 $T=\Theta(n^d)$。例如 $4T(n/2)+n$ 得 $\Theta(n^2)$。

若 $g(n)=\Theta(n^d)$，每层都为 $\Theta(n^d)$，共L层，故 $T=\Theta(n^d\log n)$。例如 $2T(n/2)+n$ 得 $\Theta(n\log n)$。

若g比 $n^d$ 多一个固定正幂，并且存在 c<1 使 $ag(n/b)\le cg(n)$，第i层成本至多 $c^ig(n)$，整棵树的非递归成本至多 $g(n)/(1-c)$。根层又必须支付$g(n)$，叶成本可被g吸收，因此 $T=\Theta(g(n))$。例如 $2T(n/2)+n^2$ 得 $\Theta(n^2)$。

注意课程把根主导情况放在“第一种”，有些书把它编号为第三种。应按条件认定情形，不能只记编号。这个证明也没有覆盖 $n/\log n$ 一类恰在边界附近的所有函数，遇到它们要回到层成本和。

## 23 · 正则条件已经包含增长下界吗

假设 $ag(n/b)\le cg(n)$，其中 0<c<1，且基础区间中的g有正下界。把式子改写为 $g(n)\ge(a/c)g(n/b)$。重复k次，有

$$
g(n)\ge(a/c)^{\mathit{k}}g(n/b^k).
$$

选k使 $n/b^k$ 落到固定基础区间，k约为 $\log_b n$。因此 $g(n)=\Omega(n^{\log_b(a/c)})$。由于

$$
\log_b(a/c)=\log_b a+\log_b(1/c),
$$

后面多出的 $\varepsilon=\log_b(1/c)>0$，正是所需的多项式间隔。若只讨论 $n=b^k$，证明直接沿这条序列成立；要推广到所有n，需要基础区间统一下界等常规条件。

反过来，光有增长下界不能约束相邻尺度的起伏。取 a=b=2，在 $n=2^k$ 上规定g：k为偶数时 $g(n)=n^2$，k为奇数时 $g(n)=n^3$。无论哪种都有 $g(n)\ge n^2$，已比 $n^{\log_2 2}=n$ 多一幂。

但当k为偶数时，$2g(n/2)/g(n)=2(n/2)^3/n^2=n/4$，随n变大，连小于1都做不到，更别说统一小于某个固定c。这个明确的反例说明，“整体长得够快”与“向下一层时有规律地衰减”是两个不同要求。

## 24 · 带对数幂的递推：别漏掉 p=-1

设 $g(n)=\Theta(n^k(\log n)^p)$，在足够大n上取对数，避免基础规模出现 log1=0。仍写 $n=b^L$。第i层的主要大小为

$$
n^k(a/b^k)^i(L-i)^p,
$$

其中换底常数已经吸收到 $\Theta$ 里。令j=L-i，就能看见几何权重和幂次怎样叠加。

若 $a<b^k$，从根向下的几何因子衰减，任何固定对数幂都无法推翻固定多项式间隔，所以 $T=\Theta(n^k(\log n)^p)$。若 $a>b^k$，叶层主导，$T=\Theta(n^{\log_b a})$。

若 $a=b^k$，几何部分恰好抵消，剩下 $n^k\sum_{j=1}^L j^p$。当 p>-1，和为 $\Theta(L^{p+1})$；当 p=-1，和是调和级数，给 $\Theta(\log L)$；当 p<-1，和有常数上界，叶成本也同阶。对应地：

$$
T(n)=
\begin{cases}
\Theta(n^k(\log n)^{p+1}),&p>-1,\\
\Theta(n^k\log\log n),&p=-1,\\
\Theta(n^k),&p<-1.
\end{cases}
$$

例如 $2T(n/2)+n/\log n$ 是 $\Theta(n\log\log n)$，不能机械套成 $\Theta(n)$。对于恰为平滑函数 $n^k(\log n)^p$，根主导时的比值最终小于1；若只知上下常数包住它，原函数可能起伏，正则条件未必逐点成立，但可用平滑上下包络和递推比较得到同一渐近界。不要把“结论可由夹逼得到”写成“所有起伏函数都自动满足逐点正则条件”。

## 25 · Akra–Bazzi：先看它解决了哪种不等分

当递归是 $T(n)=T(n/3)+T(2n/3)+n$，子问题不再是统一的n/b，前一题的同宽递归树公式不能原样照搬。Akra–Bazzi处理的核心形式是

$$
T(x)=\sum_{i=1}^m a_iT(b_ix)+g(x),\quad a_i>0,\ 0<b_i<1.
$$

先求唯一实数p满足 $\sum_i a_ib_i^p=1$，再在g非负、增长满足相应正则条件、基础区间成本有界且为正等假设下，得到

$$
T(x)=\Theta\!\left(x^p\left[1+\int_1^x\frac{g(u)}{u^{p+1}}\,du\right]\right).
$$

p是树的规模权重。一个规模x的节点分成孩子后，孩子的 $x^p$ 权重总和是 $x^p\sum a_ib_i^p=x^p$，所以在同一尺度截面上这个量守恒。于是外部工作$g(u)$按尺度累计时，需要用 $u^p$ 归一化；尺度的相对宽度是du/u，两者相乘就产生积分中的 $g(u)/u^{p+1}$。这是公式来由的解释，还不等于一般定理的完整证明。

对本题常用的不等分线性合并，我们可以直接给完整的渐近证明。令固定 $\alpha\in(0,1)$，递归分成 $\alpha n,(1-\alpha)n$，节点成本为其规模。任何一层已展开节点的规模总和不超过n，所以每层最多$O(n)$；最长路径每次至多乘 $\max(\alpha,1-\alpha)<1$，深度$O(\log n)$，得到上界$O(n\log n)$。前 $c\log n$ 层若取足够小正常数c，最小孩子路径仍未触到基础规模，这些层都完整，规模总和恰好n，于是下界 $\Omega(n\log n)$。上下合起来即 $\Theta(n\log n)$。

一般定理的严格证明还需要处理不齐的叶层、取整扰动和g的正则性，不应把上面一个特例冒充所有函数的证明。使用带 $h_i(x)$ 扰动的版本时，必须另外核对扰动界；若一个子问题实际变成n-1，它不再是固定比例收缩。后面的具体应用都会先写条件，再代入积分，而不是拿定理名代替解释。

## 26 · 最大和区间：把“哪个区间”也放进状态

先采用非空区间，使用半开写法 `[l,r)`，并约定和相同时取起点更小者，再取终点更小者。答案要保存三元组 `(sum,l,r)`，所有更新都使用同一个比较规则。

线性算法中，记 `ending` 为“必须在当前下标i结束的最佳非空区间和”，记 `start` 为它的起点。读到 `a[i]` 时，只能二选一：独立从i开始，或接到前一个结束于i-1的区间后面。若旧 `ending<0`，延长只会更差，就令 `ending=a[i], start=i`；若旧和为0，延长与重开同和，按“更小起点”应保留旧起点。

例如 `[-2,3,-1,3,-5]`：i=0时当前和-2；i=1重开得到3、起点1；i=2延长得到2；i=3延长得到5，最佳区间变为 `[1,4)`；i=4降到0，但全局最佳仍为5。最后输出的不只是5，还有元素 `[3,-1,3]`。

如果允许空区间，则全负数组的最优和为0，可以约定输出 `[0,0)`。这需要改变初始化和并列规则；不能初始化为0，却又在题面声称必须选至少一个元素。只多保存常数个下标，四种原有算法的时间阶不变，线性版额外空间仍为$O(1)$。

## 27 · 最大区间按25%与75%切，为什么没有变成二次

每个子问题在线性时间内求跨越分界的最佳区间，再加上左右递归。固定按1/4和3/4切，递推是 $T(n)=T(n/4)+T(3n/4)+\Theta(n)$。一层各节点代表互不重叠的输入区间，总长度约n，所以合并工作每层线性。

最长路径沿3/4那边下降，约经过 $\log_{4/3}n$ 层；这虽然比 $\log_2n$ 深，但仍是常数倍的$\log n$。因此总时间为 $\Theta(n\log n)$，下界可按第25题的完整浅层论证得到。

对任意固定 $\alpha\in(0,1)$ 都一样。但“固定”不能删掉：若每次切成1与n-1，最长路径有n层，层成本依次n、n-1……，合计 $\Theta(n^2)$。看见两个递归分支，不能自动认定是nlog n。

## 28 · 记忆化：缓存的键必须能决定整个子问题

以Fibonacci为例，直接递归 `F(n)=F(n-1)+F(n-2)` 会反复计算同一个 `F(3)`、`F(4)`。把已求得的F$k$存起来，再次遇到同一个k就直接读，只有n个不同状态，每个状态合并两项，因此单位字模型下时间$O(n)$、缓存$O(n)$。

可以手画 `F(5)`：左分支F$4$里会计算F$3$，右分支又要F$3$。不缓存时重新展开，缓存后第二次只取已有结果。缓存节约的是重复子问题，不会神奇地消除互不相同的所有分支。

一个常见错误是求“从位置i出发、不许用已经选过的元素”的答案，却只用i作为键。两个调用虽然位置相同，已选集合不同，剩余合法选择也不同，不能共享答案。正确键可能是 `(i,used_mask)`，状态数也随之大增。先问“相同键是否保证以后面对完全相同的问题”，再写缓存。

## 29 · LCS恢复：表里存的是长度，路径带出字符位置

设 $D[i][j]$ 表示A前i个字符与B前j个字符的LCS长度。若末字符相同，取 $D[i-1][j-1]+1$；否则取上格和左格的较大值。第一行、第一列为0，因为有一串为空。

以A=`ABC`、B=`AC`为例，完整表是：

|A前缀 / B前缀|空|A|AC|
|---|---:|---:|---:|
|空|0|0|0|
|A|0|1|1|
|AB|0|1|1|
|ABC|0|1|2|

从右下角 `(3,2)` 回溯：C相同，记录A中下标2、B中下标1，走左上到 `(2,1)`；B与A不同，上格大于左格，向上到 `(1,1)`；A相同，记录 `(0,0)`，再走左上。得到的是逆序的C、A，把记录反转就是A、C及两串中的位置。

相等的候选格可能产生多条最优路径。规定“并列优先上格”便能得到一个确定答案，但它不自动保证字典序最小的LCS；那是更强要求。保存完整长度表，计算时间$O(mn)$，回溯$O(m+n)$，额外输出长度不超过$\min(m,n)$。若原先只保留滚动两行求长度，直接回溯所需的信息已经丢掉；不能声称不增加信息就自然恢复路径。更省空间的恢复算法需要另讲分治技巧。

## 30 · 自顶向下和自底向上：同一个依赖图的两种走法

自顶向下从 `D[m][n]` 开始，需要哪个依赖就递归求哪个，算过的格子缓存。自底向上按行或列填写，保证填某格时左、上、左上已存在。两者使用同一递推关系，差别是访问顺序和实现开销。

LCS的密集最坏情形中，两个方法都可能碰到 $\Theta(mn)$ 个状态。自底向上用连续数组，容易滚动行，且没有递归栈；自顶向下贴近定义，并可能避开没用到的状态。例如两串每个末字符都相等时，沿对角线就能一路下降，不必访问整个矩形。

但若依赖图是稀疏、不规则的搜索空间，先把所有可能状态铺成表可能很浪费；反过来，状态几乎全用到而且规则，逐格填表通常更便于控制常数。先比较访问了多少个不同状态，再比较每个状态的递归、查表与内存成本，不用“递归差、循环好”概括所有情况。

## 31 · 读源码：把接口的约定也读进来

打开课程代码包后，不必第一遍就追进每个模板细节。先选一个最小调用，例如对 `[2,5,7]` 求和，找到入口、参数、递归基和返回值。把调用链写成 `sum(3)→sum(2)→sum(1)→sum(0)`，再沿返回方向累计。

对每个接口写四件事：合法输入是什么、输出保证什么、哪些对象被修改、谁负责释放资源。例如 `[lo,hi)` 中hi不属于区间；若错按闭区间传参，复杂度公式完全正确也会越界。再用空数组、单元素、全相等、最大合法下标和非法边界分开测试。

如果本机平台无法直接打开Visual Studio工程，可以读取源文件并用合适编译器编译选定项目，但需要记录这个差别，不能虚构已运行指定IDE。测试通过意味着这些输入符合预期；正确性证明还要覆盖其他合法输入。

## 32 · 看演示：先预测下一步，再按播放

演示最有价值的用法是让自己暴露误解。以反转或二分查找为例，先写当前数组、lo、hi，预测下一次交换或轴点；只播放一步，再比较。若预测错了，要指出自己把哪个区间端点或更新顺序理解错。

可以做一次具体记录：数组 `[1,4,6,9]`，目标5，用返回最后一个不大于目标的位置的C版二分。第一次看6，应把hi改到2；再看4，应把lo改到2；此时lo=hi=2，返回1，对应值4。返回值是前驱位置，不是“没找到，所以算法失败”。

动画只展示所选输入的一条执行轨迹。要把观察变成普遍结论，还要提炼不变量和终止量。纸笔预测、单步核对、写出理由，才是把演示变成可复用理解的过程。

## 本章练习：离开答案再做一次

1. $T(n)=n^3,f(n)=n^2$，判断 $T=O(f)$ 与 $\log T=O(\log f)$。说明两个判断为什么能不同。
2. 用Failstone规则追踪 `(3,5)`，数清返回值，并指出哪几步组成最大值下降的一组。
3. 非空最大和区间在 `[0,0]` 上，采用本章并列规则应输出哪个区间？若误把“旧和为0”也当作必须重开，会违背哪一条规则？

第一题：T/f=n无界，故第一个不成立；对数比值为3/2，第二个成立。第二题依次为 `(3,5),(6,5),(1,6),(1,3),(2,3),(4,3),(1,4),(1,2),(1,1)`，返回9；前三次变换后最大值从5降到3，是一组。第三题应为 `[0,1)`，和0、起点0，并列时终点1比2小。若在第二项重开会选起点1，损害先比起点的规则；若总覆盖为延长结果又会选 `[0,2)`，损害最后比终点的规则，所以全局比较也要一致。
