## 作业要求

这是你加入OJ系统中数据结构课程的唯一凭据，请及时用它加入OJ上的数据结构课程，不要泄露。

如果你在这里没有看到自己的邀请码，请在网络学堂“课程答疑”区发帖，联系助教为你发放邀请码。（补退选同学的邀请码将会在选课后第二天陆续发放）

从OJ首页 https://dsa.cs.tsinghua.edu.cn/oj/ 开始，加入课程所需的步骤为：点击绿色Dashboard大按钮->点击最上方黑色菜单“Courses”-> 点击子菜单的“join private course” -> 粘贴邀请码。
